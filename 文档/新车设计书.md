> ⚠️ **2026-09-11 蜂鸣器引脚修正**：原定 **PB8 = TIM4_CH3**，而 **TIM4 已给右编码器**（PB6/PB7 正交解码）——**同一个定时器不能既做编码器又输出 PWM**（编码器模式下计数器由轮子脉冲驱动，PWM 频率会跟着轮速跑）→ 蜂鸣器改 **PA11 = TIM1_CH4**，PB8 转备用。CubeMX 里把蜂鸣器配成 **TIM1 CH4 PWM Generation**（PA11/PA12 是 USB 脚，本车不用 USB，可安全占用）。
> 备用方案：若改用**有源**蜂鸣器，则不需要 PWM，PB8 当普通 GPIO 开关即可（状态音靠响几声/响多久实现）。
> ★**核心板插装方向（防烧板）**：2×20 排母的**第 1 脚是方焊盘**（行业约定：一脚方、其余圆，用于定位防插反），
> 必须与核心板的 1 脚丝印对齐——**插反会让 5V/GND 错位，可能烧核心板**。装车前先用万用表确认排母上 5V/GND 脚位再插。
> 复用旧核心板前必须先验证 PB8/PB9 好坏。核心板由 **5V 脚**供电（板载 LDO 出 3.3V）；底板 AMS1117 的 3.3V 只给 MPU6050/编码器/LED，**两路 3.3V 不并联、共地**。

### 3.3 电源设计
```
电池 7.4V(2S LiPo) → XT30 → 电源开关(≥5A)
   ├─→ TB6612 VM（电机功率，直接 7.4V）── 经 J_POWER 上板
   └─→ 外置降压模块(v1: MINI360 / MP1584 小模块) ── 5V ──→ J_POWER(5V_IN) 上板
            ├─→ 8路红外 / 蓝牙 / 蜂鸣器 / TB6612 VCC
            └─→ AMS1117-3.3（板上）──→ 3.3V ──→ STM32 / MPU6050 / 逻辑
```
- **7.4V**：电池输入 + 电机功率（VM）
- **5V**：8路红外、蓝牙、蜂鸣器、TB6612 VCC
- **3.3V**：STM32、MPU6050
- **必须共地**；电机电源与逻辑电源**分开走线**、加滤波电容抗干扰

### 3.3+ 电源细化
| 轨 | 来源 | 去向 |
|---|---|---|
| **7.4V** | 电池(2S LiPo) | TB6612 **VM**（电机功率）|
| **5V** | **外置小降压模块（v1）**；v2 换板上 MP1584EN/TPS5430 | 8路红外 / 蓝牙 / 蜂鸣器 / TB6612 VCC |
| **3.3V** | **AMS1117-3.3（板上 SOT-223）** | STM32 / MPU6050 |
- **电流预算**：电机 2×~1A(峰值)、8路传感 ~100mA、MCU+IMU ~50mA → **5V DC-DC 选 ≥2A、3.3V 选 ≥1A**
- **滤波**：VM 大电容；5V/3.3V 各加 10µF + 0.1µF
- 加**电源开关** +（可选）**防反接**（XT30 本身有极性，v1 可省防反接电路）
- **电机电源与逻辑电源分开走线**，全车共地
- ★**v1 用外置小模块（2026-09-11 定）**：MINI360(≈2.2×1.8cm) 或 MP1584 模块(≈3.6×2.2cm)，≥2A，¥3~5。
  **旧大模块 4.4×6.7cm 经布局逐位置核实全车无处安放（电机区/PCB区/前宽/电池旁全冲突）→ 退役留旧车**
- ★**上电流程**：模块先用万用表把输出调准 **5.0V** 再插板
- **v2 板上集成备选（存档）**：MP1584EN（首选：4.5-28V/3A/SOP-8、外围少）或 TPS5430（5.5-36V/3A/500kHz、最皮实）+ AMS1117-3.3

### 3.5 状态显示 + 启动方案（✅已定：撤 OLED，改 LED + 蜂鸣器 + 启动按键）
**撤销 OLED**。用"**LED + 蜂鸣器**"（跑动中能看/能听）+ **启动按键**。

- **LED ×3**：启动读秒 1→3、运行/错误指示（PC13 / PB14 / PB15）
- **蜂鸣器 ×1**（**无源 + PWM**，三极管/MOS 驱动）：状态音（进十字/丢线/终点）
- **启动按键 ×1**（PB9，输入 + 上拉）
- **串口 / 蓝牙**（共用 USART1）：调参 + 打印

**★蜂鸣器驱动电路（2026-09-11 定稿：照抄现成参考图，只把信号脚改成 PA11）**
```
V_5V ──┬──────────── B1 引脚1(+)            C72 (0.1µF) 跨 5V–GND 去耦
       │
   D10 (DSK14 肖特基)  ← 阴极朝 5V、阳极朝 B1 引脚2（反并联=续流，泄放反压保护 Q4）
       │
B1 引脚2(−) ──┬──── R60 (0Ω 跳线，可短接省件)
              │      C ┌── Q4 S8050 (NPN, SOT-23)
  PA11 ── R61(1k) ────┤ B
              │      └── E ── GND
       R62 (10k) ── GND      ← ★基极下拉：PA11 复位/未初始化时关断 Q4，防上电乱响
```
| 件号 | 值/型号 | 封装 | 作用 |
|---|---|---|---|
| B1 | BUZ-12-6.5（**选无源**） | — | 发声；PWM 频率=音高（常见谐振 **2.7kHz** → PWM 设 2.7kHz、占空比 50% 最响） |
| Q4 | **S8050** NPN | SOT-23 | 低边开关（GPIO 带不动 20~30mA） |
| R61 | 1k | 0603 | 基极限流（3.3V→Ib≈2.3mA，足够饱和） |
| **R62** | **10k** | 0603 | ★基极下拉（相对 GND），防浮空/上电乱响 |
| D10 | DSK14（1N4148 亦可） | SOD-123 | 续流二极管 |
| R60 | 0Ω | 0805 | 跳线，留作测蜂鸣器电流/改值；可省 |
| C72 | 0.1µF | 0603 | 5V 去耦 |
> ⚠️ 参考图信号脚是 **PA8**——本板 **PA8=循迹第3路**，**必须改成 PA11**；CubeMX 配 TIM1_CH4 PWM。
> ✅ **2026-09-11 实际画板采用**：Q1 **SS8050(SOT-23)**、D2 **1N4148W(SOD-123)**、R1 1k / R2 10k (0603)、C2 100nF (0603)，**省略 R60**（0Ω 跳线非必要）；PWM 频率设 **2.7kHz / 50% 占空比**（蜂鸣器谐振点）。

**★启动按键电路（4 脚轻触开关 KH-6X6X5H）**
```
PB9 ──┬── SW 上排(1+2 并联) ─┐
      │                     ├─ 按下导通
GND ──┴── SW 下排(3+4 并联) ─┘
      0.1µF 并联在 PB9–GND（硬件消抖，配内部上拉 ~40k ≈ 4ms RC）
```
- 4 脚开关内部 **1-2 通、3-4 通** → **每排两脚都连**（受力均匀、防翘焊盘、单脚虚焊仍可用）
- PB9 配 **GPIO 输入 + 内部上拉**（按下=低）；PB9 虽是 TIM4_CH4，但只作普通输入用，与编码器占用 TIM4 不冲突

**启动流程（★安全 + 仪式感）**：
```
上电 → IDLE(待机, 车不动)
按下启动键 → 3s 读秒: LED 逐个亮(1→2→3) + 蜂鸣器响 3 声
3s 到 → 进入 TRACK 循迹
```
> 好处：**上电不立刻跑**（车放好再按），还白送 3 秒准备时间。

**状态音设计（跑动中"听"出状态）**：
```
进十字   → "嘀"（短）
进葫芦   → "嘀嘀"（两短）
丢线     → "嘀嘀嘀"（三短/连响）
终点     → 长鸣
急停/错误 → 急促连响
```

**⚠️ 电源开关 ≠ 启动按键**：
- **电源开关**：控制电池通断（硬件）
- **启动按键**：给 MCU 信号（软件启动 → 读秒 → 跑）

### 4.1 布局（已定）
- **三轮**：**前 1 全向支撑（麦轮 0°）+ 后 2 驱动轮（带电机）**

### 4.1+ ★前支撑选型（2026-09-11 定：麦轮，但必须装 0°）

**结论**：用**麦轮**，**装 0°（滚子轴线垂直于前进方向）**，**不许按 45° 装**。

**为什么 45° 不行**（"麦轮能不能用"的真正分水岭）：

| 工况 | 装角 | 滚子自由滚动方向 vs 实际速度方向 | 结果 |
|---|---|---|---|
| 前进 | 0° | 同向 | 滚子纯滚动，**零阻力** |
| 前进 | 45° | 差 45° | 需 71% 侧向滑移 |
| **原地转/急弯** | 0° | 滚子纯滚动 | **零阻力** |
| **原地转/急弯** | 45° | 差 45° | **侧向刮擦 → 阻力** |

- 定量：前轮负载 ~200g 时，45° 装的侧向刮擦阻力 ≈ **1.1 N**；0° 装 = **0 N**。
- **更致命的是它不恒定**：麦轮一圈内装角在 0°↔45° 周期变化（1 圈 8~9 个滚子）
  → 阻力随车轮转角**脉动**，且**前进/后退/左转/右转阻力各不相同**
  → 急弯"时抓时滑"、原地转卡顿 —— **正好踩中复杂赛道的坑**。
- 又因为它是**被动轮（不驱动）**，四麦轮"侧向力两两抵消"的前提不存在，
  麦轮唯一优势（全方位平移）用不上，缺点（刮擦、脉动、贵、重、卡灰）全留着。

**为什么 0° 装成立**：滚子轴线垂直于车头方向 → 沿车头滚动时滚子纯滚动；
车身绕前支撑竖直轴扭转时同样纯滚动 → **效果等同于不带叉子的万向轮**。

**备选**：球脚轮（滚动摩擦最小、最省力，**推荐备选**）＞ 双轮万向脚轮（最稳）＞ 滑撬（最轻不卡但滑动摩擦大）。
> ❌ 麦轮 45°（学长那种）不推荐；✅ 只要满足下面硬指标，选哪个都能装。

**★ 硬指标（唯一硬约束）**：
```
前支撑【触地面 → 顶面(与底板贴合面)】= 3.30 cm = 驱动轮半径
```

**高度可调机构（★防"买错就返工"）**：底板底面用 **M3 铜柱 + 垫片** 吊住支撑，
买回的支撑高度**不用刚好**，靠铜柱+垫片凑到 3.30cm：

| 支撑裸高（安装面→触地面） | 堆叠 = 3.30 − 裸高 | 凑法 |
|---|---|---|
| 3.30cm | 0 | 轮毂/支架直接贴底板（垫片微调） |
| 3.00cm（★60mm 麦轮，推荐买这个） | 3mm | 3mm 或 2+1 垫片 |
| 2.80cm | 5mm | 3+2 垫片 |
| 2.30cm | 10mm | 3+3+3+1 垫片 |

> ⚠️ **2026-09-11 修正**：旧表把"堆叠长度"误写成"= 裸高"（照旧表 60mm 麦轮配 30mm 铜柱 → 总高 6.0cm，车头翘 2.7cm）。
> 正确规则：**总高 3.30 = 裸高 + 堆叠 → 堆叠 = 3.30 − 裸高**。详细论证见 `底板布局草案.md` §1.1。

> **下单清单（2026-09-11 修正+补充）**：M3 铜柱 20/25/30/33mm 各 4 根 **+ M3×5mm ×4（PCB 抬高用）** + M3 垫片 0.5/1/2/3mm 各 20 片 + **60mm 麦轮 ×2（1备1）** + 尼龙锁紧螺母若干（麦轮轴用，留旷量自由转）。

### 4.1++ ★关键定尺（2026-09-11 定，含重心校核）

| 项 | 定值 | 说明 |
|---|---|---|
| **轴距**（支撑 ↔ 驱动轴） | **8.5 cm** | 短轴距→转弯半径小，适合直角/连续圆环 |
| 驱动轴距板头 | **10.0 cm** | 板长 18.5，即轴距板尾 8.5 |
| **传感中心距驱动轴** | ~~5.0 cm~~ → **213mm** | ❌ 原 5.0cm 是文档内部矛盾（传感器会落在前后轮之间、比前支撑还靠后），**2026-09-18 作废**；实际 = 复刻学长车 **213mm** |
| 轮距（后轮中心距） | **11.7 cm** | 由板尾宽 15.7 反推（轮伸出板外） |
| **重心 x_cg** | **≈ −0.7 cm**（轴后 0.7cm，仍基本压驱动轴） | ★2026-09-11 重算修正（原 +0.1 系力矩加错）；质量估算待称重复核 |
| **前支撑静载** | **≈ 8%（83g）** | 轻载：牵引力仍优、原地转前轮阻力小；**必须接触地面**结论不变 |
| 单侧驱动轮静载 | ≈ 46%（×2） | 抓地力充裕，起步不易打滑 |

**解读**：重心基本压在驱动轴上（轴后 0.7cm）是**后驱最优布局**（最怕重心靠前导致起步打滑）。
代价是**前支撑仅轻载（≈8%）、主要起"防点头"作用** —— 所以：
- ✅ 前支撑**规格要求极低**（承 1kg 足够，随便买小的都行）
- ✅ 原地转时前轮几乎无摩擦 → **差速原地转更利索**
- ⚠️ 但**前支撑"必须接触地面"**——高度差 1mm 悬空就会点头/抖动
  → **§4.1+ 的可调高度机构是必须项，不是可选项**

**★ 可调余量（装好后仍可调，不用重画底板）**：
| 现象 | 调整 | 效果 |
|---|---|---|
| 前支撑太轻、过坎抖 | 电池**前移** ≤2cm | 前载 1% → 6%，更贴地 |
| 起步/加速打滑 | 电池**后移** ≤2cm | 驱动轮更压，牵引力更大 |
| 高度差一点 | 加/减垫片 | 直接凑 3.30cm |

> 电池与 PCB 都用**长条孔/多孔位**固定，允许 **±2cm 纵向滑动调重心**。
