## 0. 公式与参数

- **内切量**（车头相对轨迹切进弯内的量）：`Δ ≈ d²/(2R)`
  → 车沿圆弧走时，传感器在驱动轴前方 d 处，它「切内」Δ；Δ 越大，控制器越像"提前看到弯心"，出弯车尾甩外、压到另一条线。
- **外廓外扩**（转弯时前外角扫出去的半径）：`R_out = √((R+B/2)² + L_front²)`，外扩 = R_out − R
  → 必须 **< 赛道上相邻两条线的最小间距**（这个数你要实地量！）
- **等效转向增益** ∝ d：**d 缩短多少倍，KP 起点就要放大多少倍**（表里给系数）
- **航向分辨率** = atan(12.9/d)（12.9mm = 8 路条的探头间距）：d 越短，分辨"车头歪了几度"的能力越差 → 这是"前瞻不能无限缩"的另一面

固定参数：赛道最小圆环 **R=342mm**、线宽 **25mm**、轮距按 **B=165mm**、传感支架前伸 **20mm**（板子前缘比传感器中心再前 20mm）。

## 4. 做长条板的注意（防返工）

1. **5mm 亚克力**（3mm 在 100mm 悬臂上会颤 → 传感器离地 5~8mm 一颤就误判，你会误判成"这档不行"）
2. **两排孔**：间距 = 8 路模块背面两条长条孔的中心距（**先量，别按感觉打**）；模块长条孔本身有 17mm 可调量 → 配 10mm 孔距，细调很够
3. **板上刻数字**（70 90 110 130 150）——不然跑完就忘了哪档
4. **M3 沉头/平头**螺钉，别凸出来刮地；每档**左右各一颗**（一颗会歪 → 左右不对称）
5. 模块**离地 5~8mm**（铜柱/垫片调），**板前端别翘**（翘 = 前瞻悄悄变大）
6. **线留 10cm 松弛**或做插座 → 换档不用重焊
7. 长条板与底板的连接处**也留 10mm 孔距**（二级调节），这样整根条能前后挪，覆盖更大范围
