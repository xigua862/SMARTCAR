# 任务卡-V2-M0-骨架与接口冻结

- 日期：2026-10-02　写卡人：军师　依据：`文档/框架定稿-v1.md`（已签字）§②§③§⑨
- 背景：v2 分支从零重写，第一期只搭骨架：接口定死 + 1kHz 节拍 + 数据通路打通，**不含任何算法与判据**。
- 目标：编译烧录后，架空/手推就能在 CSV 遥测里看到正确的 IR 位图、ERR、编码器计数、里程 mm、ISR 耗时；串口命令可控电机点动。

## 步骤（照做，不做设计决策）

### 1. 目录与工程
- 新建 `Core/App/v2/`，下分 `drv/ mid/ ctl/ app/` 四子目录。
- 在 `MDK-ARM/test16.uvprojx` 里**手工**加 Group "AppV2"（四子目录各一），把下面所有新 .c 加入编译。**禁止跑 CubeMX 重新生成**（有破坏工程事故先例）。

### 2. 头文件（函数签名冻结，注释标"冻结@M0"）
按框架 §② 清单建 20 个 .h。归属与关键约定：
- `mid/mid_types.h`：定义跨层结构体 `line_reading_t{uint8_t bitmap; uint8_t active; int16_t err_x100;}`、`pose_t{int32_t od_mm; int32_t yaw_mdeg; int16_t dps_x100;}`、`track_event_t`（M2 才用，先占位枚举）。
- `drv/` 10 个：`motor.h line_sensor.h encoder.h imu.h odom.h pose.h buzzer.h led.h key.h uart.h`
- `mid/track.h`、`ctl/` 5 个：`steering.h angulate.h speeds.h pid.h filter.h`、`app/` 5 个：`car_fsm.h param.h tune.h telemetry.h selftest.h`
- **新符号一律加 `v2_` 前缀**（`v2_motor_init`、`v2_line_read`…），避免与旧 app 树重名。
- M0 允许空 .c 的模块：`pose.c track.c steering.c angulate.c param.c tune.c selftest.c`（.h 必须存在且签名完整；.c 只写 include + 空初始化函数，标 `TODO(M1+)`）。

### 3. drv 实现（只这几个要有真代码）
- `v2_line_sensor.c`：8 路位带读（表：左→右 PA0 PA1 PA8 PA15 PB0 PB1 PB12 PB13，权重 -7…+7，**白=高**）；突发过采样 8 次/1µs 间隔/多数表决（照旧 `line_sensor.c` 的算法搬，常量写死在本文件顶部并注明）。`err_x100 = 100*Σ(w·s)/(Σs+1)`（框架 §④，整数算）。
- `v2_motor.c`：TIM2_CH3=PA2 / CH4=PA3（10kHz，ARR 预装载）+ DIR PA4/PA5、PB3/PB4；`MOTOR_LEFT/RIGHT_INVERT=1/1` 沿用现值（回报里注明"沿用实测定稿值"）。
- `v2_encoder.c`：读 TIM3/TIM4 计数，16 位回绕安全 Δ 计算，`v2_enc_take_delta(chn)`。
- `v2_odom.c`：1kHz 调用 `v2_odom_tick()`：Δ 积分 → `od_mm`；`UM_PER_COUNT=491`；**绝对值法**（`(|dL|+|dR|)/2`，沿旧 odom 修过的符号坑结论）。
- `v2_imu.c`：**不重写 I2C**，包旧 `imu.c`（`MX_I2C2_Init` 保留）；主循环 100Hz `v2_imu_poll()` 刷缓存（dps_x100、yaw_mdeg）；ISR 只读缓存，禁止在 ISR 里发起 I2C 读。
- `v2_uart.c`：USART1 PA9/PA10@115200；RX 中断→256B 环形缓冲；TX 用 `HAL_UART_Transmit` 阻塞（M0 可接受，回报里记"TX 阻塞实测占用 xx%"）。
- `v2_buzzer.c`：TIM1_CH4/PA11。TIM1 时基 = **1kHz 更新中断**（PSC=71, ARR=71）；蜂鸣频率靠 CCR4 脉冲密度近似 1.4kHz，注释写明"M0 只验证不冲突，音调质量 M4 再调"。
- `v2_led.c / v2_key.c`：照旧 `led.c/key.c` 搬（PC13/PB14/PB15 高亮；PB9 上拉按下低，消抖 3 tick）。

### 4. 1kHz ISR 骨架（放 `v2_buzzer.c` 的 TIM1 初始化 + `app/v2_app_task.c`）
`TIM1_UP_IRQHandler` 内容固定顺序：DWT 时间戳起表 → `v2_line_read()` → `v2_enc/odom tick` → 中环/内环 **stub**（输出 0，即电机不动）→ 哨兵：本次耗时 >300µs 置 `overlong++`；全程无浮点、无 printf、无 I2C。

### 5. 主循环与遥测
- `main.c` USER CODE 区：`app_init/app_loop` 调用整体 `#if 0` 关掉（保留文字说明），改调 `v2_app_init()/v2_app_loop()`。旧树其余文件**不删不编译改动**（M0 只做加法；删除在后续里程碑按期执行）。
- `car_fsm` M0 只实现 IDLE；T 命令直接驱动 motor stub。
- CSV 行（10Hz）：`$V2,FW,ms,IR(bmp),act,err_x100,ODmm,YAWmdeg,GZx100,ISRus,OL,CT`（ISR 耗时均值 µs、overlong 计数、控制拍计数）。
- 命令（M0 只这几个）：`V` 版本 / `T <1|2> <pwm>` 点动 / `Z` 里程清零 / `X` 单次急停（清 T 状态，电机停）。FW_TAG=`"M0-<date +%m%d-%H%M 真实时间>"`。

### 6. 编译与烧录
- `_tmp/build.ps1` → **0 Error 0 Warning**；从编译输出抄 Code/RO/RW 进回报。
- 烧录 CMSIS-DAP：`openocd -f interface/cmsis-dap.cfg -c "transport select swd" -f target/stm32f1x.cfg -c "adapter speed 1000" -c "program MDK-ARM/test16/test16.hex verify reset exit"`（烧录与读串口不同时）。
- **串口采集必须用 pyserial**（PowerShell 逐行读会大量丢行，旧坑）。

## 验收标准（逐条对照回报）
1. 开机横幅含 FW_TAG + 编译时间，`V` 有回。
2. 手遮任一通道 → CSV `IR` 对应位变化；白线上居中 → `act=1~2` 且 `|err_x100|≤200`。
3. 架空手转左轮一整圈 → 对应通道 Δ 计数 = 422±10%；右轮同测；**两路方向符号记下写进回报**（L=/R= 谁正谁负）。
4. 推车沿直线 1.00m → `OD` 读 950~1050mm。
5. 静止 10s → `YAW` 漂移 <1°（不达标：车放稳重新上电再测——陀螺零偏要求上电瞬间绝对静止）。
6. `T 1 30`/`T 2 30` 两轮正转、`T x 0` 停；`X` 急停生效。
7. `ISRus <150` 且 `OL=0`（>0 则回报附 ISR 内各步分段时间）。
8. 编译数据：Code ≤40K；RAM 静态（RW+ZI）≤10K。
