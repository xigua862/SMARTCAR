# 串口命令表 · FW 1008-R122（2026-10-16 从 telemetry.c 逐条抠出）

> ★**车上固件现为 `FW:1016-R149`**（= R122 + 本机改动：迟滞/冷却、`TIM:`、判据定参、葫芦段降速窗口 + 里程挂 IG、**S 57 固定**（静态 57/40）、**速度窗口表**（起步 36→57 / 直角弯前减速）、**起步斑马线忽略**、串口免回车、里程打点 `TIK`/`END`）。
> **命令语法没变**；**★2026-10-16（R132）起不回车也能用**（见下面的解析规则）。用 `V` 命令看横幅确认版本号即可。

> 串口 = **DAPLink 虚拟口（本机 COM11）@115200**；不是老的 CH340。
> 解析规则（★R132 起更新）：
> - 带 `\r`/`\n` 结尾：**照旧认**。
> - **★免回车**：不回车的命令靠"**静默自动提交**"——攒了内容、且距最后一个字符 **≥400ms** 就当成一条完整命令（等价于收到回车）。
>   为什么用"静默"而不是"来一个字符就执行"：后者会把参数命令切碎（打 `S57` → 先执行 `S`＝0 速！）⇒ 危险。
> - **★单个 `X` 不自动提交**（急停要连发两个 X）：第一个 X 最多等 **1500ms**；等不到第二个才提交（回 `USE: XX …` 提示）。两个 X 打得够快 ⇒ **不带回车也能急停**。
> - ★**参数命令必须带数值（R132 安全阀）**：`P` / `S` / `D` 不带数字 ⇒ 直接拒绝（`ERR S needs a value`）。
>   原来 `atof("")=0` 会被当成 0（`S`→车速清零、`D`→KD 清零），打字慢/被分包时就会踩到。
> - 其余照旧：**首字母大小写都认**；参数支持 `P15` 和 `P 15`；`T`/`M` 两个参数用**空格**分隔；行长上限 31 字符；**白名单外的命令静默丢弃（不回话）**。

## 三、短行字段怎么读

```
FW:1016-R130 TIM:123456 IR:00011000 RPM 128/4 P 18/29 C -5 S 24 OD 3475 GZ -50 IG 1
```

| 字段 | 含义 |
|---|---|
| `FW:` | 固件版本（确认烧的是哪版）|
| **`TIM:`** | 当前时刻（ms，轮询时钟）——发车那行当 t0，后行减它 = 相对发车多久 |
| `IR:` | 8 路位图，**第 1 位 = 最左**，**1 = 看到白线**（例：`00011000` = 中间两路）|
| `RPM L/R` | 左右轮实测转速 |
| **`P L/R`** | **真正下发**的 PWM —— 和 RPM 对照能分岔：P 给了 33 而 RPM 0 ⇒ 速度环/反馈问题；P≈RPM 都低 ⇒ 电机/机械没劲 |
| `C` | 本拍**差速修正** corr（±99）—— 弯里看它摆多大 |
| `S` | 速度基准 sp（自适应两级：直道档 = S，弯道档 = S×0.7）**★1016-R130 起提速目标 = 57** ⇒ `S 57` 时提速不再改速度、只亮三灯；**葫芦段窗口内（OD 11176~12844）这里会显示窗口档 36/24** |
| `OD` | 净里程（mm，从发车算）|
| `GZ` | 偏航率（°/s，**正 = 左转**）|
| `IG` | 是否在葫芦圈内（1=在圈，**GW/切点逻辑只在 IG=1 时工作**）**★1016-R131 起：葫芦段窗口内（OD 11176~12844）由里程强制为 1**（不再依赖陀螺判据；出窗口回到陀螺判据自管）|
| `GW` | **葫芦圈"相切点"计数**（0~2，数到 3 自动归 0）：只在 `IG=1` 时累加；判据 = 只贴一端 + 亮 5~6 路 + 陀螺 `GZ` 在 ±8 拍内翻号 + 间距 ≥200mm。**它不出现在短行里** —— 只在 `MARK#… GW=…`（TIK 打点）和 `GOURD-TANGENT … GW=n` 两处出现。★**目前它不驱动任何动作**（用它的两条出口判据都关着），只是计数/诊断用；实测数得不准（有假计数），**别拿它当判据** |

## 四、调参工作流（重要）

1. **`P/S/D` 改的是内存，掉电即失效** ⇒ 调出好数后要写回 **`Core/App/app_config.h`**（`KP`/`KD`/`SPEED_STRAIGHT`/`SPEED_CURVE`），重新编译+烧录；
2. 本机烧录（验证过）：
   ```bash
   "C:\Users\asus\AppData\Local\Programs\xpack-openocd-0.12.0-7\bin\openocd.exe" ^
     -f interface/cmsis-dap.cfg -c "transport select swd" -f target/stm32f1x.cfg ^
     -c "adapter speed 1000" -c "program MDK-ARM/test16/test16.hex verify reset exit"
   ```
3. 读串口脚本：`_tmp/readdap.ps1 -Seconds 5`（自动找 DAPLink 的 CDC 口）。
