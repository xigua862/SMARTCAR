## 一、比赛信息（规则）

- **时间**：10月底
- **赛道**：白底赛道（**赛道旁是蓝色**），赛道**中间一条"电工线"**作循迹线
- **循迹方式（可选其一/组合）**：
  - **CC 循迹**（CCD/灰度）
  - **摄像头（视觉）循迹**
  - **红外循迹**
- **任务**：**高速、完整地跑完一圈**，然后在**终点停下**。
- **终点 = 起点**：在"一条**电工线垂直贴着循迹线**"的地方（即横向终点标志线）。车跑到那里要**停下来**。
- **判定**：速度 + 完整性（不脱线跑完一整圈）+ 终点停得准。

## 三、技术方案（重制版）

### 1. 传感（选型）
- **红外**（你现有）：对"白底黑线/深色线"好；**但"电工线"若是金属/反光，红外可能误判** → **第一步先验证对比度**（车悬空或放在线上看 IR 读值）。
- **CC（CCD/灰度）**：抗光、梯度稳定，比纯红外稳，适合高速。
- **摄像头**：上限最高，但**复杂度/算力/时间成本最大**；10月底时间紧 → **先别上**，除非你认定要冲视觉。
- 🎯 **建议**：**先用红外/灰度（趁手 + 便宜）+ 加"终点横线检测"**，高速够用；时间紧别贪摄像头。

### 2. 终点线检测（关键新增）
- 终点 = **一根垂直于循迹线的电工线**（横线）。
- 检测思路：**5 路红外排一条横线**，当**多路同时检测到线（近似全触发/横线经过）**时判为"终点横线"→ **急停**。
- 或单独加**一路横向传感器**，专门扫横线。
- 注意：**别把"直角/十字/环岛"误判成终点**（区分"多路同时有"vs"横线"）；用**连续几帧确认 + 只在快到终点才认**。

### 3. 主控
- 你现在 **STM32F103（HAL）够用**（红外/灰度 + 电机 + 霍尔 + 串口调参）。保留你现有代码/调参体系（在线调参、tune.ps1）。
- 只有上摄像头才考虑更强主控（F4/OpenMV 等）。

### 4. 电机/驱动
- 现有 **N20（减速）偏慢** → 想"高速"要评估：**换更大扭矩/更快的电机**，或**提高电压**，或**换更高电流驱动**。
- ⚠️ 但校赛赛道小、太快易冲出 → **速度与稳定平衡**；驱动按电流选（TB6612 或更高）。

### 5. 结构/布线（治"乱"）
- **模块化分区**：电源/MCU/驱动/传感 分层，别挤成一团。
- **排线走线规矩**：热缩管/扎带、线束固定、减振缓冲、车架加固。
- 用你**重打的沉金板**按"成品"重排——**让它像台正经小车，不是飞线堆**。

### 6. 供电
- 电池 + 稳压（**电机/核心板分路供电防干扰**）、**共地**、比赛前满电。

### 7. 控制算法（核心升级）
- **循迹**：PD 差速（你会）。**高速要重新调好 P/D**，防蛇形/冲线。
- **速度自适应**：直道快、弯道慢（用 IR 误差判弯道 → 自动调速）。
- **控制周期**：**10ms**（比你现在 20ms 修正密度翻倍）。
- **终点检测 + 刹车**：检测到横线 → 加**急停/制动**（别冲过头）。
- 进阶：**速度闭环**（霍尔/编码器反馈 → PID 稳速）。

## 四、从"现在车"到"重制版"升级清单

| 项 | 现状 | 重制目标 |
|---|---|---|
| 结构 | 飞线乱、不整 | 模块化 + 规矩布线，像成品 |
| 速度 | 慢（N20 低）| 提速 + 速度自适应 |
| 循迹 | 高速不稳 | 10ms + PD 调到高速稳 |
| 终点 | 无 | 加横线检测 + 急停 |
| 供电 | — | 分路稳压 + 抗干扰 |

## 五、知识补齐清单

- **控制**：PID 深入（防蛇形/冲线）、速度闭环、状态机、滤波（低通）。
- **传感**：红外/灰度标定、终点横线检测（别误判直角/十字）。
- **硬件**：供电/稳压、抗干扰、布线规范、万用表/示波器排障。
- **调试**：串口/上位机实时看数据、参数化、整圈数据复盘。
