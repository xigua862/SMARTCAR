## 三、决定性证据

### 证据 1：**纯 PD 阶段 error 一路在收敛**

```
拍 0-7（G=0，纯 PD）：+9 → +4 → 0 → 0 → +3 → +4 → +8 → +8
```
**没有发散，一直在跟线。** 这正是队友文档里"通用 PD 就正确进了下一个圆"的实车复现。

### 证据 2：**开环在"红外还看得见线"的时候就接管了**

拍 10~13 的红外**明明还在报 error = +16 / +15 / +15 / +12**（要求强左转），
但 `G=1/2` = 开环盲走，**把这些指令全部丢弃** → 车照直走 → 第 15 拍全灭。

**如果这四拍交给 PD**：error 从 +16 降到 +12 —— **正在收敛的路上**。

### 证据 3：**触发时刻决定成败 → 这就是"有时候没问题"的原因**

- 触发时车身正好对齐 → 盲走可能"碰巧"走对
- 触发时车身偏着（如本日志拍 8）→ 盲走直接冲出去

用户原话"**有时候是没有问题的，有时候会直直的开出去**" —— 完全对上。

## 四、结论

**开环方案不是"没用"，是"有害"**：它把一个**本来在正常工作的 PD 控制器强行关掉**，
换成一段不受任何反馈约束的盲走。

**正确做法**：
1. 葫芦圈内**交给 PD**（不给它加任何开环动作）
2. 只在**真正的出口**做那一下转向（本条日志里没走到出口就丢线了）
3. 把力气花在**不干扰 PD** 上：
   - 圈内屏蔽丢线兜底（防被拽走）
   - 单路掉路容忍（相切处最边传感器熄灭时别丢转向力度）
   - 后半段减速（让 PD 跟得上曲率突变）

## 五、次要发现：两轮转速明显不平衡

```
RPM1（左轮）多在 130~150
RPM2（右轮）多在 56~108      ← 右轮慢很多
```

旧固件**没开速度闭环**，所以这是开环 PWM 下两电机的固有差异。
新固件已开 `USE_SPEED_LOOP=1`，正好能治这个 —— **但 PID 需要整定**。
