# 动手前考虑清单（防踩坑）

> **用途**：每次"下单/买件 / 画 PCB / 画底板 / 搭车 / 写代码"**之前**先过一遍，避免"没想清楚就动手 → 返工浪费"。
> **约定**：以后每次要动手前，**Claude 主动按本清单帮我把关**（用户不用记）。
> 血泪教训：2026-09-10 搭车翘头（没买匹配的万向轮）、电机到了却没线（没算配套耗材），白白浪费一下午。

---

## 一、通用模板（任何事前，先自问）
1. **目的**：做这个是为了什么？做成"什么样"算成功？
2. **要哪些件**：不光是主体，还有**配套耗材**（螺丝/铜柱/线材/连接器/胶带/电源）——★最容易漏。
3. **关键尺寸/接口**：实际装起来会是什么样？会不会互相打架？
4. **结果预期**：把"装好的样子"**画出来/量出来**，别凭感觉。
5. **最大风险**：最容易翻车的是哪一步？
6. **兜底**：万一不对，能补救/可调吗？

---

## 二、画底板（结构设计）专项清单

### A. 顺序：先定什么（有依赖关系，别跳）
1. **驱动轮直径** → 决定**车轴中心离地高度**（= 半径）
2. **电机安装**：固定孔位/支架 → 决定电机中心高、轮子位置
3. **万向轮总高 = 驱动轮轴心离地高** → **【防翘头】★（这次就栽这）**
4. **轴距**（驱动轴↔万向轮，目标 10~15cm）、**轮距**（两驱动轮间距）
5. **传感位置**：离地 ~1cm、与地面平行(0°)、**贴近驱动轴(5~10cm)**
6. **电池/PCB 位置** → 重心尽量低、**电池压在驱动轴上方**
7. **底板外形 + 安装孔**（对齐电机支架、PCB 孔、传感支架、铜柱）
8. **配套件清单**（见 C）
9. **加工方式**：亚克力切割 / 3D 打印 / 直接用 PCB 当底板（重量、强度、成本）

### B. 必查项（逐条打勾）
- [ ] **三点着地**：前万向轮 + 后两驱动轮 **都着地**、车不摇
- [ ] **万向轮高度 = 驱动轮半径** → 车**水平、不翘头**（★核心）
- [ ] 传感：离地 ~1cm、**与地面平行**、靠近驱动轴
- [ ] 重心低；**电池在底层、压驱动轴**
- [ ] 电机/轮子/万向轮 **不打架**、不挡传感视线
- [ ] **配套件齐**：螺丝、铜柱、**电机线**、连接器、扎带/热缩管
- [ ] **装配顺序**能装得上、也能拆下维修
- [ ] 下载口/开关/充电 位置方便

### C. 配套耗材清单（下单前必查，这次漏了电机线）
| 类别 | 要确认的 |
|---|---|
| 结构 | 螺丝(M2/M3)、螺母、**铜柱**、底板材料 |
| 电机 | **电机线/延长线**、编码器连接器(6pin)、固定支架 |
| 传感 | 传感支架、排线、**电位器调节工具** |
| 电源 | 电池、DCDC/LDO、**开关**、XT30/接线端子 |
| 电路 | PCB 连接器(排针/母座)、杜邦线、焊锡 |

## 三、"下单前"最后一遍（别急着点购买/发板）
- [ ] 所有**尺寸量过/算过**（不是猜的）
- [ ] 所有件列了**清单**，缺的**一次性补齐**
- [ ] 脑子里/纸上**过一遍"装好的样子"**，有没有明显不对
- [ ] 有没有**可调/平替**方案（如万向轮高度用垫片可调、孔位留可调余量）
- [ ] **量三遍、切一次**（画板/切割同理：先出图核对，再下单）

---

## 四、写代码前专项（顺带）
- [ ] 这个功能的**输入/输出**是什么？（谁给我数据、我控制谁）
- [ ] **引脚/外设**够不够？会不会和别的冲突？
- [ ] **参数**从哪来（宏/在线调参）？
- [ ] 怎么**验证**它对不对（串口打印？现象？）
- [ ] 改动会不会**破坏已验证的部分**？
