# 电压记录 · 跑车台账（没有稳压 ⇒ 每趟必记）

> **为什么要这张表**：我们**没做 VM 稳压**（他的原话："我们没做 VM 的稳压导致现在要记录电压"）。
> 电池电压掉一点，电机实际转速、打滑、里程计换算全跟着变 ⇒ **同一版代码在不同电压下表现不同**。
> ⇒ 每趟发车前量电压、跑完记结果。**别在没对电压的情况下改参数**。

## ★★ 2026-10-21 破案：**12.4V 才跑得通，差一点都不行**

他的原话：**"破案，12.4V 才能跑通，老子绷不住了，差一点都不行"**。

**为什么这么敏感（机制）**：
1. **右编码器坏 ⇒ 右轮开环**（`R=0`，速度环被 `SPD_DEAD_FB_GUARD` 退回开环）⇒ 右轮 PWM→实际转速的换算**随电压漂**；
2. 左轮闭环、右轮开环 ⇒ **两轮的速度比随电压变** ⇒ 直行会偏、转弯半径会变、里程（`|L|+|R|` 合成）跟着变；
3. 我们所有阈值（切点窗口、槽③、出口门槛…）都是**里程**判据 ⇒ 里程一漂，全线错位 ⇒ 表现成"差 0.1V 就全崩"。

⇒ **"电压敏感"不是新毛病，它是"右编码器坏 + 没稳压"的合并症状。** 修好右编码器，这一条会大幅缓解。

**下一步建议（按性价比）**
1. ★**修右编码器**（PB6/PB7、霍尔供电/焊点）—— 根治，收益最大；判据：手推 3m 发 `O`，`R` 不再为 0。
2. **量"带载电压"**（现在量的是空载）：跑起来时同一块表盯着，空载 12.4V 满载可能只有 11.5V —— 若差值 >0.5V，先查电池内阻/线径/接头。
3. 硬件小改：电池线**加粗 + 缩短**、换 XT30/XT60 接头、驱动 VM 处并 **470~1000µF 低 ESR 电容**。
4. 固件（我可以做）：**分压进 ADC 读电池电压**，塞进遥测行 ⇒ 以后每条日志自带电压标签。（注意：**别用 CubeMX 重新生成**，有事故史；手工加 ADC 初始化。）


## 用法

1. 每趟发车**前**：万用表量电池（或看他车上的电压显示），填 `电压(V)`。
2. 跑完填 `结果`：`✅ 全程` / `⚠️ 某段`（写清哪段）/ `❌ 失败`（写现象）。
3. 同一版本、**电压差 ≥ 0.3V** ⇒ 当成新工况，先别改代码，先对照本表。
4. 判"是代码变了还是电压变了"：**先查这张表**。
