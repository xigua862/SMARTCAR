# 电压记录 · 跑车台账（没有稳压 ⇒ 每趟必记）

> **为什么要这张表**：我们**没做 VM 稳压**（他的原话："我们没做 VM 的稳压导致现在要记录电压"）。
> 电池电压掉一点，电机实际转速、打滑、里程计换算全跟着变 ⇒ **同一版代码在不同电压下表现不同**。
> ⇒ 每趟发车前量电压、跑完记结果。**别在没对电压的情况下改参数**。

## 用法

1. 每趟发车**前**：万用表量电池（或看他车上的电压显示），填 `电压(V)`。
2. 跑完填 `结果`：`✅ 全程` / `⚠️ 某段`（写清哪段）/ `❌ 失败`（写现象）。
3. 同一版本、**电压差 ≥ 0.3V** ⇒ 当成新工况，先别改代码，先对照本表。
4. 判"是代码变了还是电压变了"：**先查这张表**。
