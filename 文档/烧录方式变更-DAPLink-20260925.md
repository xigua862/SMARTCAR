## 5. ⚠️ 一个必须记住的坑

商家给的配置图是 **STM32F407VGT6** 的，本工程是 **STM32F103C8**：

- **Debug 页**的设置跟芯片无关，可以照抄 ✓
- **`Flash Download` 页的下载算法千万别照抄** ✗
  本工程必须是 **`STM32F10x_128`**（`STM32F10x_128.FLM`）✓

## 6. 踩过的弯路（省得再走）

- 改 `.uvprojx` 的 `<TargetDllName>` → 报 `BIN\BIN\... not found` 或 `invalid debug Dll` ✗
  （那里只是 AGDI 内核，**调试器的选择在 `.uvoptx` 的 `<pMon>`**）
- 只改 `<pMon>` 不补 `<TargetDriverDllRegistry>` → 报 `Internal DLL Error` ✗
- 手改 `.uvoptx` 半天，不如 **GUI 里点一次 OK** —— Keil 会自动把 `<pMon>` 和 `<Key>` 都写对 ✓✓✓

### 6.1 ★命令行烧录的实测细节（2026-09-26 晚，G80 那次，务必照抄）

**① 调用方式：只能用 `Start-Process -Wait -PassThru`，不能用 `&`**

```powershell
# ✗ 这样【静默失败】：没有进程、没有日志、产物时间不变、$LASTEXITCODE 还是空的
& "C:\keil5\UV4\UV4.exe" -r "<proj>" -j0 -o "$env:TEMP\x.log"

# ✓ 这样才行（能拿到退出码 + 日志）
$p = Start-Process -FilePath 'C:\keil5\UV4\UV4.exe' `
     -ArgumentList @('-f','<proj>','-j0','-o',$log) -Wait -PassThru
$p.ExitCode
```

- 编译：`-r`；编译+下载：`-f`；`ExitCode = 0` = 成功
- 日志成功标志：`"test16\test16.axf" - 0 Error(s), 0 Warning(s).` / 烧录：`Erase Done. Programming Done. Verify OK.`

**② 失败是常态，先原样重试 2~3 次**（同一命令、不用改任何东西）

| 现象 | 本次实测 |
|---|---|
| `Programming Failed! RDDI-DAP Error` + `Flash Download failed - "Cortex-M3"` | 第 1 次 |
| `Internal DLL Error` + `Target DLL has been cancelled` | 第 2、3 次 |
| `Erase Done. Programming Done. Verify OK.` | **第 4 次成功** |

⚠️ **失败那次的日志里已经有 `Erase Done`** ⇒ **芯片当时已经被擦除、旧固件没了**。
所以"烧失败"不等于"还是旧版" —— **必须一直重试到 `Verify OK` 才能收工**（本次最后是 23:18:08 成功的）。

**③ 烧完怎么确认烧的是哪版（回读没了以后的替代）**

1. `test16.axf` 里直接搜 ASCII 的 `FW` 标签（本次 `0926-G80` 命中 4 处）；
2. `test16.hex` 里搜字节序列（`0926-G80` = `303932362D473830`）；
3. 最终仍以**串口第一行的 `FW:`** 为准 ✓

## 7. 沙箱限制（环境相关）

- 工作区路径含中文 → spawn 的 python 收到乱码路径，venv 建不起来 ✗
  （所以没走 pyOCD 路线；真要用，得把环境建在纯英文路径下）
- `git log -S "..."`（pickaxe）在本沙箱里会崩：`sh.exe: couldn't create signal pipe, Win32 error 5`
  ⇒ 要用 `git log --oneline | Select-String` 或直接 `git show <tag>:<file> | Select-String` 代替
- ⚠️⚠️ **这个 shell 是 Windows PowerShell 5.1（不是 PS7）：不要用 shell 改写含中文的文本文件。**
  `Get-Content` / `Set-Content` / `-replace` 会按**系统 ANSI(GBK)** 读、按 UTF-8 写 ⇒ 整篇中文变乱码
  （2026-09-26 深夜就这样把 `文档索引与状态.md` 写坏，只能用 `git checkout -- <file>` 恢复后重做）。
  ⇒ **改文本一律用编辑工具**；非要用 shell，必须显式编码：
  ```powershell
  $t = [System.IO.File]::ReadAllText($p, [Text.Encoding]::UTF8)
  [System.IO.File]::WriteAllText($p, $t, (New-Object Text.UTF8Encoding($false)))
  ```
