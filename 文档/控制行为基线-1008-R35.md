## 0. 前提（硬件与时基）

| 项 | 值 | 说明 |
|---|---|---|
| 主控 / 时基 | STM32F103C8T6，控制拍 **10ms（100Hz）** | 所有"拍数"常量都按 10ms 计 |
| 循迹 | 8 路数字红外，**bit0 = 最左**，**1 = 看到线**（白色） | 显示串 `IR:01100110` 的第 1 位就是 bit0 |
| 通道权重 | bit0..bit7 = **-7, -5, -3, -1, +1, +3, +5, +7** | `line_error` 用**置位（=1）**的通道加权求和 |
| 速度单位 | PWM（±99），速度环目标 = PWM × 5.5 → RPM | |
| 里程 | `odom_distance_mm()` = 累计路程，**只增不减** | 右轮测速断线时约为真实路程的一半 |
| 编码器 | 左 TIM3 / 右 TIM4；**右轮测速长期不可信、左轮间歇** | 断线的那一轮由 `SPD_DEAD_FB` 判出后**退回开环** |

## 1. 一拍内的流水线（严格按此顺序）

```
① line_read()                     → raw(8位位图) + error(重心误差)
② s_gourd_armed = (里程 ≥ GOURD_ARM_MM) && !s_gourd_done          【里程闸门】
③ 选误差来源（优先级从上到下，先命中者胜）
     丢线(dc > LOST_SPIN_DELAY)  → 原地旋转找线（LOST_SPIN_SPEED）
     十字 / 直角                 → 各自的分支处理
     分支口接管（BRANCH-EDGE）    → e = 该侧最外 N 路的加权和（见 §3）
     正常                        → e = line_error（经 D 滤波器 α=D_FILTER_ALPHA）
④ corr_pd = KP_eff·e + KD·d_term      KP_eff = 圈内 GOURD_KP / 圈外 KP
⑤ corr    = corr_pd + trim(转向记忆)   稳态 ≈ 需求差速的 40%
⑥ 速度基准 sp：直道 SPEED_STRAIGHT / 弯道 SPEED_CURVE（|e| ≥ CURVE_ABS_ERR_THRESH 算弯道）
              ★R35 起【没有】葫芦圈减速（GOURD_EXIT_SLOW_EN = 0）
⑦ m1 = sp + corr     m2 = sp - corr     （±99 限幅）
⑧ 速度环（每轮增量式 PID，KP=SPD_PID_KP）覆盖 m1/m2
   该轮被判定测速断线 ⇒ 跳过 PID，直接用开环命令（前馈 = 本意 m）
⑨ 保护层（顺序不可换）
     a) PWM 下限：|m| ∈ (WHEEL_FLOOR_MIN_CMD, WHEEL_PWM_FLOOR) → 抬到 ±WHEEL_PWM_FLOOR
     b) NO-STOP-BRAKE：**跟着本意**——本意正→ m ≥ +WHEEL_MIN_ROLL；
        本意负→ m ≤ -WHEEL_MIN_ROLL；本意 0 → 不动
     c) REV-CUT：某一轮连续"被压到 < MIN_ROLL"超过 WHEEL_REV_MAX_FRAMES 拍
        ⇒ 强制抬回 +WHEEL_MIN_ROLL 并锁存，直到该轮本意转正
⑩ 出圈判据（见 §4）
⑪ 黑匣子记录（见 §5）
```

## 3. 分支口接管（BRANCH-EDGE）—— 最核心、也最容易改坏的一处

```
【触发】gate && 亮路数 ≤ CROSS_ACTIVE_MAX(6) && ( 团数 ≥ 2  或  (团数 = 1 且 亮路数 ≥ 5) )
        gate = s_gourd_armed                     （里程闸门）
        团 = 位图里 1 的连续段；"两坨"= 两条线被中间的黑撕开
        防抖 = 连续 BRANCH_EDGE_CONFIRM(2) 拍 && 距上次 ≥ BRANCH_EDGE_MIN_MM(250)mm
【取法】误差改成"该侧最外 2 路"：
        向右 → 从 bit7 往 bit0 扫，取最先遇到的 2 个置位通道
        向左 → 从 bit0 往 bit7 扫，同样取 2 个
        例：位图 01100110（亮在 1,2,5,6）
            向右取 00000110（第 6、5 路）⇒ e = +5+3 = +8
            向左取 01100000（第 1、2 路）⇒ e = -5-3 = -8
        ★是相对【亮的那一段】的最外，不是相对整条 8 路的两端
【相位】s_be_next_l 左右交替；**每次翻转只前进一格**
        翻转条件 = "两坨"状态的【上升沿】：上一拍无两坨 && 这一拍有两坨
        ★两坨状态与它的历史必须【每拍更新】（R34 修的 bug：只在触发被接受时更新
          ⇒ prev 永远停在 1 ⇒ 第二个切点之后相位不再翻转 ⇒ 台账出现 L,R,R,R）
【退出】连续回到普通线若干拍，或保持超时
★已知缺陷：换误差源发生在 D 滤波器【之后】⇒ 接管瞬间 e 可跳 ±16 ⇒ 过切点左右晃
  （治法：挪到滤波器之前，或给它单独加斜率限制 —— 属"已知待改"，重构时【保持现状】）
```

## 4. 出圈（当前处于标定模式）

```
判据⑤：里程 ∈ [GOURD_EXIT_WINDOW_MM ± WIN_HALF]  且  出现 T 形图案
       图案 = 当前拍位图 【或】 1kHz 窗口里最宽的那张位图（s_1k_maxraw）
       ★GOURD_EXIT_CALIB_ONLY=1 ⇒ 这一段不编译 ⇒ 物理上不可能转向
候选图案记录：armed 之后每见一次候选就存一条到 RAM（od/raw/raw1k/mx/inwin），最多 24 条
判据②（圈内持续丢线）已关闭；③里程 / ④GW 也未启用
一次进圈只转一次（ONE_SHOT）；转向成功置 s_gourd_done ⇒ 闸门随即关闭
```

## 5. 黑匣子（诊断核心，重构时必须逐字段保持）

```
每 TRACE_DECIM(5) 拍记一条，环形 130 条 = 6.5 秒
字段：od, oL, oR, gz, pwl, pwr, ir, de, dcor, dsp, ddcy, dflg
冻结条件：净里程连续约 1 秒不变（= 车停下就冻，冻的是"最后 6.5 秒行驶画面"）
         ★R28 起关掉了"第一次圈内丢线就冻"（它总在起步 1.1m 处冻住）
台账 s_be_log：每次分支口触发记一条（8 字节：od/side/act/nb/w1），最多 16 条
诊断消息（一次性）：NO-STOP-BRAKE / REV-CUT / gourd 相关
```

## 6. "行为零变化"的验收清单（重构每一步都跑一遍）

1. **编译 0 错 0 警**（本项目硬要求）；
2. 烧录后串口横幅的 `FW:` 与 `OD/IR/PWM/e/cor` 各列格式不变；
3. 跑一趟葫芦圈，从芯片读出的三项与基线对照：
   - **台账侧别必须严格交替** `L R L R L R L`（7 个切点）；
   - `s_fb_dead` 与基线同状态（左 0 / 右 1 或有线材问题时的 1/1）；
   - `GE`、`ge_fired`、`armed` 的取值规律不变；
4. 常量表（§2）逐项 grep 对照，一个都不许变；
5. 直道不抖、弯道不晃、直角弯不被误接管（这三条是主观项，但必须与基线一致）。
