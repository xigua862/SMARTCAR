## 2. ★★ 国一源码里最值得 A 车抄的：**圆环状态机**

来源：`test16/开源工程/飞檐走壁-STC32G源码/Project/code/adc.c`（作者 get_lucky()，第 21 届飞檐走壁组国一第二，**已实车验证**）。

A 车现在最痛的"葫芦圈/出圈判据"问题，这套逻辑**结构上正好对症**：

| 状态 | 迁移条件（源码原意） | A 车可怎么落地 |
|---|---|---|
| `NONE → ENTER` | 电感阈值 + **编码器里程到点**（`in_ring_dis_x=5000` / `in_ring_dis_d=8000`） | **里程窗口 + 误差形态**（连续 N 拍 `\|ERR\|` 同向饱和）双判据 |
| `INSIDE` | 环内**强制固定偏置** `ERR = ±r_offset`（小环 35 / 大环 50），靠陀螺 **`angle_integral_Z`** 计角度 | ★**绕环期间不要再用循迹误差闭环**，直接给固定偏置 + 里程/角度积分收尾——这正是"出圈判据打坏直角弯"的解法方向 |
| `→ EXIT` | `angle_integral_Z > 60°` | 角度积分阈值，与传感器无关，**可原样搬** |
| `→ LEAVE` | `angle_integral_Z > 340°` 或 `ring_tim ≥ 500` 超时复位 | 同上；**超时兜底**很值得学（判据失效也能出来） |
| 环编号 | 12 个环位、小环/大环分表 | A 车按本赛道只有 **E 区 4 环 + C 区 1 环**，表更短 |

**另外两条可抄**：
- **差比和误差**：`sub = (A·(LX−RX) + B·(LY−RY))·100`，`add = A·(LX+RX) + C·|LY−RY| + 1`，`ERR = sub/add` —— 分母带"亮度和 + 1"，**天然抗整体反射率漂移**（换场地/光照变化时比"加权质心"稳）。
- **上电自检 + 参数落 EEPROM**：`eeprom` + `sys_param_load` + 5 向按键 + 蜂鸣器提示 → A 车现场调参工作流的标配。

**一条别学（坑）**：源码 `speed_control()` 里失线就 `while(1){ motor_control(0,0); }` **死循环停车** —— 红外抖一下就当场停死。A 车的停车判据必须是"**8 路全黑 + 连续 N 拍 + 里程窗口内 + 圈数达标**"多重与。

## 3. 起终点/斑马线判据（把 A 车"两套出口触发并行竞态"收敛成一套）

规则给了确定的几何：**斑马线间距 50mm、S↔G 间隔 400mm、线宽 25mm**。
→ 车过斑马线时，8 路会打出**"整排同时压白 + 50mm 周期"**的特征；而 400mm 间隔给了**明确的里程窗口**。

建议判据（**单一出口，删冗余**）：
```
在 [里程窗口] 内 ∧ (连续 2~3 拍 8 路中 ≥6 路为白) ∧ (圈数 == 目标圈数) → 触发终点动作
```
配合一条纪律：**判据只留一套**，另一套改成默认关闭的调试开关（对应当前待办 `复查-出口触发冗余盘点-20260924.md`）。

## 4. 硬件/电源通则（A 车画新板、摆模块时逐条过一遍）

和 `事故-连环烧板-机械短接-20260927.md` 是同一条战线，这次又攒了几条：

1. **TVS 钳位电压 = 电池 S 数的硬上限**（B 车那颗 `SMAJ16CA` 16V → 严禁 4S）。新板先定 TVS 再定电池。
2. **连接器额定电流必须 ≥ 峰值电流**：2.0mm 间距座只有 2~3A，动力线一律 **XT30** 起。
3. **30 秒估堵转电流**：万用表欧姆档量电机两端 DCR，`I_stall ≈ V满电 / DCR`。B 车那颗负压风机 5Ω → 2.5A，**和预算完全吻合**，A 车的驱动电机也该各量一次记进文档。
4. **满电电压常超电机额定** → 用 **PWM 上限**（如 90%）做保护，比换电池灵活。
5. **防反接二极管（SS54 级）保留**，别为省一个元件赌接线。
6. **反射式红外三板斧**：**3.3V 供电**（别 5V 打 GPIO）· **遮光**（每套管黑色热缩管 + 整条遮光罩；赛场日光灯/阳光含红外，裸管会漂到不可用）· **离地 3~8mm 固定死**（禁悬空叠装——和烧板事故同一条规矩）。
7. **碳刷电机是 EMI 源**：两端并 100nF + 磁珠，代码里留上电自检 + 蜂鸣提示，现场 30 秒排掉一半故障。
