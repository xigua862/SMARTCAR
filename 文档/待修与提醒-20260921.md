## 一、待修 Bug：丢线"停车防跑飞"被 uint8 回绕抵消了

**位置**
- `Core/App/control/line_follow.c:15` —— `static uint8_t lost_cycles = 0;`
- `Core/App/control/line_follow.c:86-99` —— 丢线旋转 / 停车分支
- `Core/App/app_config.h:64` —— `#define LOST_MAX_CYCLES 150`

**当前代码**

```c
if (line_lost)
{
  if (lost_cycles > LOST_MAX_CYCLES) { motor_stop(); }        /* 设计意图: 找不到线就停车防跑飞 */
  else if (last_error >= 0) { motor_set_differential( 35, -35); }
  else                      { motor_set_differential(-35,  35); }
  return;
}
```

**问题**：命中停车分支后 **`lost_cycles` 没有重置**，而它是 `uint8_t`。

| 拍数 | 行为 |
|---|---|
| 0–2 | 短暂丢线：`e = last_error × 2` 沿原方向修正 |
| 3–150 | 原地旋转找线（±35） |
| 151–255 | `motor_stop()` 停住 |
| **256（回绕）** | `lost_cycles` 变成 0 → **又回到"旋转"** → 再停 → 再转… |

**实际行为**（1 拍 = `CTRL_PERIOD_MS` = 10 ms）：**转 1.5 s → 停 1.05 s → 又转 1.5 s → …** 无限循环，永不真正停住。
→ "防跑飞"这个安全设计**被类型回绕抵消**了：丢线时车会在原地一直打转。

**两种改法（选一个，并把意图写清楚）**
- **想真停**：`lost_cycles` 改 `uint16_t`，或在停车分支里把它钉死（`lost_cycles = LOST_MAX_CYCLES + 1;`）+ 给个 `stopped` 标志；
- **想要脉冲搜索**（"停一会再找"）：把现在这个行为**显式写成**"停 N 拍后重试"，别靠类型回绕来兜。

**2 分钟复现**：车架空（四轮离地）、用纸/手把 8 路传感器全挡住 → 计时看轮子：
按设计应约 1.5 s 后停住；**实际是停 ~1 s 后又自己转起来**，如此反复。

## 二、待确认：葫芦弯到底是靠哪一层过的（test17 里**没有**葫芦状态机）

`line_follow.c` 里只有四样东西，没有 GOURD 状态：速度自适应 / 十字判定 / 丢线兜底 / PD。
能过葫芦靠的是三套**通用**兜底凑出来的：

| # | 位置 | 干什么 |
|---|---|---|
| ① | `line_follow.c:38-51` | 速度自适应：`\|e\| ≥ CURVE_ABS_ERR_THRESH(3)` → 降到 `sp_curve`（60 → 42） |
| ② | `line_follow.c:68-72` | 短暂丢线：`e = last_error × 2`（沿上次方向**加倍**修正） |
| ③ | `line_follow.c:86-99` | 持续丢线：原地旋转找线 |

**验证方法（别推理，用数据）**：跑动时遥测是 **20 Hz**（`app_config.h:54`，`TELEMETRY_PERIOD_RUN_MS 50`）。
把过葫芦那几秒的串口日志存下来，看 `IR:` 位图：

- **从不出现 `00000000`** → 是 **①降速 + PD** 过的，兜底没参与（说明当前几何/25 mm 线宽下葫芦并不难）；
- **全 0 后 1–2 拍恢复** → **②在救**；
- **全 0 且长时间维持**（`ST` 停在丢线态很久）→ **③在救** → 同时去看第一节那个 Bug。

**第②层的失效模式**：`e = last_error × 2` —— 如果丢线那一刻车**正好居中**（`last_error ≈ 0`），
翻倍还是 0 → **不修正，直着冲出去**。相切点恰好压中心时就会撞上。

## 三、以后把 test161 的葫芦逻辑搬进来时，注意三件事

参考实现：`..\test161\Core\Src\main.c`（**参数在第 42–47 行，状态本体在 169–201 行**）
`GOURD_ENTRY_HOLD 3` / `GOURD_STEP_BEATS 4` / `GOURD_STEER 30` / `GOURD_SPEED_PCT 60` / `GOURD_MAX_CYCLES 150`

1. **图案撞车（最危险）**：test161 里 终点 = `10101`、葫芦 = `00101`，**只差最左一路**，而 TRACK 中**先判终点**。
   进葫芦时车位稍歪、最左被扫到 → 会被判成**终点 → 停车自锁**。
   → 解药就是你新 FSM 里留的那个 TODO：**终点 = 图案 + 里程双条件**（`Core/App/fsm/car_fsm.c:128`）。**先做这个，再搬葫芦。**
2. **别按"拍"打节奏**：test161 那个固定数组是按 10 ms 拍数计的 → **绑死速度**，一改 `BASE_SPEED` 就得重调 `GOURD_*`。
   → 改成按**编码器脉冲（距离）**计数：编码器已配好（`app_config.h:112-120`，TIM3/TIM4 正交解码，422 PPR）。
   正好是 W3 那条线，而且不再绑速度。
3. **保留现有兜底**：test17 这套"降速 + 丢线加倍修正 + 旋转找线"对入口角度更鲁棒。
   搬状态机时**把它留作 fallback**（认不出葫芦就照常循迹），不要只留开环节奏。
