# 事故：连环烧核心板 + 调试器（记录于 2026-09-27）—— 已破案：外挂稳压模块针脚短接核心板

> 一句话：**12V→5V 稳压模块是外接的、用杜邦线连、摆在核心板正上方；模块背面伸出的针脚碰到核心板 → 短接 → 核心板烧，
> 调试器连着时过压/大电流顺 SWD 反灌，把 DAP-Link 一起带走。**
> 记录人：AI（按他现场复盘代笔，2026-09-27）；与 CARD-00x 固件工作无关——这是**机械结构**的事故。

---

## 一、事实

| 项 | 内容 |
|---|---|
| 损失 | 核心板 ≥2 块、DAP-Link ×1；另有一块 C8T6 的 SWD 连不上（9-27 用 ST-Link 实测 `init mode failed`、目标电压 3.20V 正常，待确认是否也是受害者） |
| 现场的布置 | 稳压模块**外接**（杜邦线连到核心板）、空间位置在**核心板正上方**、模块背面针脚**向下裸露** |
| 触发 | 针脚"伸出来一点点" → 碰到核心板上的导体 → 短接 |

## 二、机理

1. 裸露针脚把 12V/5V 直接打进核心板的其它网络（3.3V / 5V / SWD / IO）；
2. 12V 压进 3.3V 域 = **芯片瞬死**，任何软件/保护都来不及；
3. 调试器连着时，过压/大电流沿 SWD 线反灌 → **DAP-Link 一起烧**；
4. 布置没变 = 凶手没走 → "又烧一个"是同一个短接在不同时间复现。

## 三、整改规矩（写进习惯）

1. **任何背面有裸露导体的模块，禁止悬在另一块板子正上方**——哪怕"看起来差一点点够不到"。
2. 外挂模块必须**固定死**（尼龙柱/扎带/3D 打印支架）；只用杜邦线连的模块一律当"会晃的东西"对待。
3. 层叠三件套：**支柱定间距 + 背面绝缘垫（胶带/绝缘纸/塑料片）+ 针脚剪短**（齐根剪，别剪到焊盘）。
4. 调试器规矩加一条：**动接线/挪模块之前先断电；上电前目视检查无裸金属相碰**。
5. 新板对策：**把 5V 电源模块画进板子**（正在做）——从结构上消灭"模块叠模块"。

## 四、对新板设计的影响（画板时对着检查）

- 电源链路：DC 座（**2A 上限**）→ **PTC `SMD0805-050-16`/`-24`**（0.5A 保持 / 1.0A 跳闸 / ≥16V；`-6`、`-12` 结尾的版本别选）→ 开关（**3A 只够逻辑，电机电流别走它**）→ 5V 模块；
- 12V 输入端加 **TVS**（如 SMBJ15A）+ **大电解 100~470µF/25V**；有条件再加反接保护（SS54 或 PMOS）；
- 8 路模块 VCC 走 **3.3V**（PA0/PA1/PB0/PB1 不耐 5V）；供电从 5V 换成 3.3V 后，"白线输出高"的实测门槛要**重新量一次**；
- **说实话的部分**：PTC 管"持续短路/防起火"，**救不了芯片瞬死**（热跳闸太慢）——这次的正确解法是机械绝缘，不是保险丝。

## 五、对既有判断的修正

- 之前怀疑的"**DC 座瞬断打火**"**降级**为次要嫌疑（真正死因已由现场确认）；
- 核心板/调试器都是被**机械短接**打死的，与固件、与烧录流程无关。
