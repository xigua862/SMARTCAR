## 0. 先记住"两种节拍"

| 节拍 | 位置 | 干什么 |
|---|---|---|
| **1kHz（1ms）** | `SysTick_Handler` → `line_sample_1khz()`（`stm32f1xx_it.c:207`）| 每 1ms 多采一次红外位图，**只观测/统计**（看 100Hz 漏掉了什么一闪而过的图案），不改行为 |
| **100Hz（10ms）控制拍** | `app_loop()`（`app.c:92`）| `speed_update()` → `telemetry_trace_tick()`（黑匣子）→ `car_fsm_run(10)` → … → `line_follow_control()` |
| 100Hz UI 拍 | `app.c:58` | `key_update()` 消抖 / `buzzer_update()` / **`imu_update()`（读陀螺+积分航向，I2C 在这里）** / `odom_update()`（里程累加）|
| 遥测 | `app.c:110` | 待机 **500ms** 一行；读秒/运行中 **50ms** 一行 |
| 串口命令 | `app.c:122` 每圈 | RX 中断攒行 → `telemetry_process_command()` 解析 |

★ 所以"寻线"的**全部**控制在 10ms 一拍里；1kHz 那层是取证用的。

**状态机 `car_fsm_run()`（`car_fsm.c:159`）**

| 状态 | 行为 |
|---|---|
| `IDLE` | `motor_stop()`；**长按 = 出发**（9-24 晚把"长短按"换过：原来短按出发）|
| `COUNTDOWN` | 3 步读秒（灯逐个亮 + 每步一哔）→ 到点：**`odom_reset()` + `line_follow_gourd_rearm()`** → `RUN` |
| `RUN` | LED2 丢线闪烁；**`line_follow_control(base_speed)` ← 所有寻线逻辑都在这一个函数里** |
| `STOPPED` | `motor_stop()` + 三灯 2Hz 闪；长按再跑一次 |
| `EMERGENCY` | 三灯快闪；**按住启动键 2 秒回 IDLE**；进入瞬间**自动回放最近 600 拍轨迹**（IR/GZ/OD，`car_fsm.c:109`）|

- 运行/读秒中：**短按或长按都 = 暂停**（急停）；待机/到站的短按只被吃掉、不动作（`car_fsm.c:205-218`）
- `AUTO_STOP_MM`/`AUTO_RUN_MS` = 0 → 自动停车关（`CFG:349-350`）
- `CAR_RUN` 里还留着一句 `TODO(终点)`（`car_fsm.c:285`）——**已过时**，终点停车实际在 `line_follow.c` 的 R108 模块里

## 6. 串口命令 + 遥测（`telemetry.c`）

**命令**：`P<KP>` `S<速度>` `D<KD>` 调参 · `Q` 轨迹回放 · `H` 完整长行（含 IR 位图/按键/编码器/IMU）· `O` 读里程 · `Z` 里程清零 · `T <1|2> <速度>` 单电机（架空）· `M <左> <右>` 双轮直给 · `L <0~7>` 点灯 · `B [ms]` 蜂鸣 · `V` 版本横幅 · `R` 串口启动 · `XX` 急停（**必须连发两个 X**，防噪声）· `TEST <秒>` 只循迹 n 秒后停车并回放轨迹

**遥测**：默认短行 = `FW: <版本> TIM: <ms> IR: <位图> RPM L/R P(下发PWM) L/R C(修正) S(速度基准) OD GZ IG`；细节靠 `H`；PC→车 RX 不通时，用**长按急停**触发自动回放（`car_fsm.c:109`）。
**`TIM:`（2026-10-16 加）**= `HAL_GetTick()` 毫秒（轮询时钟）——发车那行当 t0，后面每行减它 = 相对发车多久；放在 FW 之后（前部，防行尾被吃）。
