## 一、两个已定项（本次结论）

### 1.1 前支撑类型 → **球脚轮（2026-09-16 改定）**，配「M3 铜柱 + 垫片」可调高度

> ★ **2026-09-16 变更**：前支撑由"麦轮 0°"改为 **球脚轮（万向滚珠 / 牛眼轮）**——滚动摩擦最小、原地转最省力，
> 本来就是原文档的"**推荐备选**"。下面麦轮 0° 的论证保留作历史记录。
>
> **球脚轮选型算法（务必遵守）**：
> ```
> 总高 3.30cm = 球脚轮裸高 + 铜柱/垫片堆叠     堆叠只能加、不能减
> → 球脚轮裸高必须 ≤ 33mm，且尽量接近 33mm（否则要垫很长的堆叠）
> → 推荐：球径 20~25mm 法兰式万向球（总高约 26~31mm），配 2~8mm 铜柱/垫片凑 3.30cm
> → 禁止：球径 ≥30mm（总高 >34mm，矮不下来）；螺杆式/弹簧式（无法与铜柱对接）
> ```
> **装配注意**：球脚轮法兰孔距一般 20~30mm，与底板"前支撑孔 z=±3.0cm"对不上
> → 用一块 **30×30mm 小转接板**（亚克力边角料/废 PCB）：两孔对上底板 z=±3.0，球脚轮拧在转接板下，中间夹铜柱堆叠调高度。


**结论**：用**麦轮**，但**不许按 45° 装**——要装成 **0°（滚子轴线与前进方向垂直）**。

**为什么 45° 不行**（这是"麦轮能不能用"的真正分水岭）：

| 工况 | 麦轮装角 | 滚子自由滚动方向 vs 实际速度方向 | 结果 |
|---|---|---|---|
| 沿车头方向前进 | 0° | 同向 | 滚子纯滚动，**零阻力** |
| 沿车头方向前进 | 45° | 差 45° | 需 71% 侧向滑移 + 29% 滚动 |
| **原地转 / 过急弯** | 0° | 滚子纯滚动 | **零阻力** |
| **原地转 / 过急弯** | 45° | 差 45° | **侧向刮擦 → 阻力** |

- 定量：前轮负载 ~200g 时，45° 装的侧向刮擦阻力 ≈ **1.1 N**；0° 装 = **0 N**。
- **更致命的是它不恒定**：麦轮一圈内装角在 0°↔45° 之间周期变化（1 圈 = 8 或 9 个滚子），
  → 阻力随车轮转角**脉动**，且**前进/后退/左转/右转四个方向阻力各不相同**。
  → 转弯时前轮"时抓时滑"，表现就是**急弯忽左忽右、原地转卡顿**——正好踩中"复杂赛道"的坑。
- 又因为它是**被动轮（不驱动）**，四麦轮那种"前后左右侧向力两两抵消"的前提根本不存在，
  麦轮唯一的优势（全方位平移）用不上，缺点（滚子刮擦、脉动、贵、重、缝里卡灰）全留着。

**为什么 0° 装就成立**：
0° 时滚子轴线垂直于车头方向 → 沿车头滚动时滚子**纯滚动**；车身绕前支撑竖直轴扭转时也一样，
因为滚子磨损后天然形成"圆柱面"绕着竖直轴转——**效果等同于一个不带叉子的万向轮**。
（这也是"麦轮平装/全向轮"的用法，常见于无动力随动轮。）

**"那买个万向轮不更省事？"——是的**，所以给你留了备选（见 §1.2），
**0° 麦轮是"既想用麦轮、又不想卡"的折中**，两者都满足硬指标。

**★ 硬指标（不论选哪个都必须满足）**：
```
前支撑【触地面 → 顶面(与底板贴合面)】= 3.30 cm = 驱动轮半径
```

**高度可调机构（★防"买错就返工"的关键设计）**：
```
底板底面 ────────┬──────── M3 螺钉
                 │  ← 垫片（0.5 / 1.0 / 2.0mm）微调
              铜柱 │  ← M3 铜柱/垫片堆叠（长度 = 3.30 − 裸高）
                 │
        麦轮/万向轮顶面 ── 支撑触地面 y=0
```
| 支撑裸高（安装面→触地面） | 堆叠 = 3.30 − 裸高 | 凑法 |
|---|---|---|
| 3.30cm | 0 | 轮毂/支架直接贴底板（垫片微调） |
| 3.00cm（★60mm 麦轮，推荐买这个） | 3mm | 3mm 或 2+1 垫片 |
| 2.80cm | 5mm | 3+2 垫片 |
| 2.30cm | 10mm | 3+3+3+1 垫片 |

> ⚠️ **2026-09-11 修正**：旧表把"堆叠长度"误写成"= 裸高"（照旧表 60mm 麦轮要配 30mm 铜柱 → 总高 6.0cm，车头翘 2.7cm）。
> 正确规则：**总高 3.30 = 裸高 + 堆叠 → 堆叠 = 3.30 − 裸高**。
> **采购清单不变**：垫片足够凑 0~13mm 任意堆叠；20/25/30/33mm 铜柱留给 PCB 抬高等其他用途。
> ★**装配细节**：裸麦轮当 0° 随动轮必须能绕轴自由转 → M3 螺钉穿轮毂作轴 + 尼龙锁紧螺母留 ~0.5mm 轴向旷量（或买带支架款），装车当天验证。

> **好处**：买回来的支撑高度**不用"刚好"**，靠铜柱+垫片凑到 3.30cm，
> 彻底避开上次"万向轮高度不匹配 → 白装一下午"的坑。
> **铜柱下料清单（下单时一次买齐）**：M3 铜柱 20/25/30/33mm 各 4 根 + **M3×5mm ×4（PCB 抬高用）**，M3 垫片 0.5/1/2/3mm 各 20 片；**前支撑推荐买 60mm 麦轮 ×2**（1备1）。

### 1.2 备选方案（如果不想要麦轮）

| 方案 | 优点 | 缺点 | 结论 |
|---|---|---|---|
| **球脚轮（万向滚珠）** | 滚动摩擦最小、原地转最省力、最矮、便宜 | 需选到接近 33mm 总高的型号，否则垫片要堆高 | **推荐备选**，追求急弯性能选它 |
| **双轮万向脚轮** | 最稳、承重最大（>5kg），行李箱脚轮满街都是 | 略重，摆动有回正力矩 | 稳妥派 |
| **滑撬（POM 圆头螺栓/尼龙滑块）** | 最轻、最矮、**不可能卡死**、高度无级可调 | **滑动摩擦大**，原地转比滚动费力 | 赛道是光滑白板时可选 |
| **麦轮 45°（学长那种）** | 手感"专业" | 见 §1.1，急弯会脉动卡顿 | ❌ 不推荐 |

### 1.3 电池高度 → **1.8 cm**（待实测确认）

- 已知 长 **6.4** × 宽 **3.5** cm；高度按 **1.8cm** 建层高（2S 2200mAh 常见厚度）。
- ⏳ **到货/现有电池请用卡尺量最厚处（含平衡头、线受压处），量最大处**，量到就替换本数字。
- 影响：电池决定"底层高度 0.3~2.1cm"和整车高度。**若实测 >2.0cm，只需把 PCB 铜柱加高即可，布局不用重画**（见 §3 可调余量）。

### 1.4 降压模块 → **v1 外置小模块**（2026-09-11 定）

- 决定：**DCDC 暂不集成**，v1 用**外置成品降压模块**（MINI360 ≈2.2×1.8cm 或 MP1584 模块 ≈3.6×2.2cm，≥2A，¥3~5）出 5V；3.3V 由板上 AMS1117-3.3 从 5V 降。
- ★**旧大模块（4.4×6.7cm）放不下**：按 §2.1 布局逐位置核实——顶部后区被电机（z=±5.0, x=−6.0~+1.0）占、中部被 PCB 占、前区板宽仅 7.5 且挂传感器、电池旁纵向 6.4+6.7=13.1 > 可用 10.5，**全冲突** → 退役留旧车。
- v2 再板上集成（备选存档：MP1584EN 首选 / TPS5430）。
- 小模块安装位见 §2.1 表；**上电前先用万用表把输出调准 5.0V 再插板**。

> **★ 用户实际布局（2026-09-18 提供，单层紧凑板，无空余）**：
> 从**驱动轴（后轮）**往车头排：**降压模块段 38mm**（模块横放，占纵向）→ **PCB 段 70mm** → **车头球脚轮段 74mm**；
> **传感中心距驱动轴 = 213mm**，**板总长 ≈ 229mm**。
> → 本文档原来的"传感距驱动轴 50mm"是**理想目标值，单层板不可能达到**，**正式作废**，以 213mm 为准。
> **代价与对策**：前悬大 = 有提前量（可预判弯道），但等效几何增益约为 50mm 方案的 4.3 倍 → **KP 起步调小（旧车 10 → 试 2~3）**，速度自适应阈值重调，必要时加 D 项/低通滤波抑制摆头。

> **★ 前瞻距离（= 传感中心到驱动轴）行业数据 · 2026-09-18 查证（来源：CSDN）**：
> - **定义**（CSDN《智能巡线小车的设计》）："**前瞻 D1 是指红外巡线电路板到动力车轮的距离**。合适的前瞻值可以提前获取黑线信息，减少反应延迟，提高循迹效果。"
> - **竞赛级 CCD 车实测**（CSDN 经验贴，19 届 STC-CCD）："**下排 CCD 前瞻 35~45cm、上排 60~75cm 效果最好**；把上排调到 **80cm，圆环识别率直接掉到 50% 以下**"（→ 前瞻过长会失稳）
> - **视觉方案**（CSDN《…从图像处理到PID调参》）：图像底对应车头前 **15cm**、顶部对应 **120cm** 是理想范围；**判据：前瞻 ≥ 车速 × 链路总延迟**（1m/s × 80ms ≈ 8cm）
> - **电磁单车竞赛**：前瞻固定于车前方 **20cm**、高 15cm
>
> **对照本车 213mm**：车速上限 ≈1.3m/s（7.4V/380rpm/φ66 轮）→ 延迟位移 ≈10cm → **前瞻余量近 2 倍 ✓ 合理**；
> 比玩具级红外循迹（5~15cm）大（提前量更足），比竞赛级 CCD 车（35~75cm）小（更保守好调）。
> → **结论：213mm 保留不改**；原文档的"5.0cm"作废（那是套用"传感在两轮之间"车型的经验，与本车布局无关）。
> → 调参含义：前瞻大 → 等效增益高 → **KP 起步试 2~3**（旧车 10），并配合 D 项/低通滤波压摆头。

## 二·0、★底板外形定义（2026-09-16 补：原来只给了三个宽度，这里定出轮廓）

**坐标系**（画图必须按这个，否则孔位全错）：
- **x 以驱动轴为 0**，**+x 向车头**、−x 向板尾；**z 为宽度方向**（左 −、右 +）；板厚 **3mm**
- 总长 **185mm**：板头 **x=+100**，板尾 **x=−85**
> 📌 **SolidWorks 建模时坐标换法**（2026-09-16）：SW 里用 **Y = 车长方向**、**X = 宽度方向**、**X=0 为对称轴**（先画右半边再镜像）。
> 对应关系：**文档 x ↔ SW 的 Y**、**文档 z ↔ SW 的 X**，数值一一照抄。**+Y 朝车头**（板头 Y=+100）。
> ⚠️ 板形**不对称**（前端 75 vs 后端 157），镜像后务必量：Y=+100 处宽 75、Y=−85 处宽 157。

**轮廓（窄头宽尾，四段 + 两段过渡）**：

| x 范围 | 半宽 \|z\| | 全宽 | 说明 |
|---|---|---|---|
| +100 ~ +30 | ±37.5 | **75** | 前段（长 70）：前支撑 x=+50、传感器支架都在这里 |
| +30 ~ +15 | 线性过渡 | 75 → **135** | 斜边过渡 |
| +15 ~ −10 | ±67.5 | **135** | 中段（长 25）：**含驱动轴**，驱动轮在此处略微探出板外 |
| −10 ~ −30 | 线性过渡 | 135 → **157** | 斜边过渡 |
| −30 ~ −85 | ±78.5 | **157** | 后段（长 55）：电机支架孔、降压模块、电池槽 |

- 所有外角**倒圆 R5**（防割手、也避免亚克力尖角开裂）
- 若激光切割厂家要求单文件，直接导出 DXF（见 §四 末尾）

### 2.1 纵向定位表（★核心，以驱动轴 x=0 为基准）

| 部件 | 纵向中心 x (cm) | 纵向占用 (cm) | 横向占用 (cm) | 高度区间 (离地, cm) | 备注 |

> ⚠️ **PCB 与传感器纵向重叠（0.5~5.0cm）是允许的**：传感器只占中间 3cm 宽（\|z\|≤1.5），
> PCB 抬高到离地 4.0cm，而传感器顶面 2.5cm、支架顶 3.3cm → **垂直方向留 0.7cm 净空**，互不干涉。
> ⚠️ **PCB 宽度硬约束：横向 ≤ 7cm（z ±3.5）**（2026-09-11 补）：电机本体在 z=±5.0、直径约 25mm（内缘 ≈±3.75cm），
> 车轮内缘 ≈±4.55cm；而 PCB 高度带 4.0~5.6cm 与电机带 2.5~6.0cm、车轮带 0~6.6cm **重叠** → **板子可以加长，不要加宽**。
> ⚠️ **PCB 与底板的 4 个安装孔必须同坐标**（建议 **x=±3.5cm、z=±3.0cm**；**\|z\| ≤ 3.0 是硬约束**，超过会撞电机）。

  离地
  5.6 ┌──────────────────────────────┐  ← PCB 顶
  4.0 └──────────────────────────────┘  ← PCB 底（铜柱抬升段）
  3.3 ═══════════════════════════════════════  ← 底板底面 ★全车基准高度
  2.5      ┌──────────────────────┐            ← 传感器顶 / 支架顶 3.3
  2.1      ▓▓▓▓▓▓ 电池 ▓▓▓▓▓▓                   ← 电池顶（贴底板上表面）
  1.0      └──────────────────────┘            ← 传感器底面 ★离地 1.0cm，0° 平行
  0.3    ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓                    ← 电池底
  ──────────────────────────────────────────── 地面 y = 0
         ↑                      ↑
     前支撑触地            驱动轮触地
     (总高 3.3cm)         (半径 3.3cm)
```

**★ 防翘头等式（唯一硬约束）**：
```
前支撑触地面→顶面  3.30 cm   ==   驱动轮半径  3.30 cm
```
只要这一条成立，三点着地、底板水平、不翘头。

## 三、重心与载荷分配（可调余量）

### 3.1 质量估算与重心

| 部件 | 质量 (g) | x (cm) | 力矩 (g·cm) |
|---|---|---|---|
| 8路传感器 + 支架 | 100 | +4.5 | +450 |
| 前支撑总成 | 70 | +5.0 | +350 |
| 驱动轮 + 轮毂 ×2 | 90 | 0 | 0 |
| 电机 + 支架 ×2 | 320 | −2.5 | −800 |
| 电池 | 115 | −1.2 | −138 |
| PCB + 元件 | 120 | 0 | 0 |
| 底板 + 紧固件 + 线材 | 250 | −2.0 | −500 |
| 降压小模块 (v1) | 10 | −6.8 | −68 |
| **合计** | **≈ 1075** | **x_cg ≈ −0.7** | −706 |

> ⏳ 质量为**估算**（按同类件经验值），到货后称重替换即可，方法不变。
> ⚠️ **2026-09-11 重算修正**：原表合计力矩 −638 g·cm ÷ 1065 g 应为 **x_cg = −0.60cm**（原文写 +0.1 系加错）。
> 计入小模块后为 **−0.7cm**。结论不变：**重心仍基本压驱动轴（轴后 0.7cm），后驱布局成立**。

### 3.2 三点载荷（轴距 8.5cm）

```
F_front = W × |x_cg| / 轴距          （以驱动轴取矩）
```

| 项 | 数值 |
|---|---|
| 总质量 | ≈ 1075 g |
| 重心 x_cg | **≈ −0.7 cm**（轴后 0.7cm，仍基本压驱动轴）★2026-09-11 重算修正 |
| 轴距（支撑↔驱动轴） | **8.5 cm** |
| **前支撑静载** | ≈ 83 g（**7.7%**）→ 轻载（原表 12g/1.1% 系重心加错连带，已修正） |
| **单侧驱动轮静载** | ≈ 496 g（**46.1%**）×2 → 抓地力充裕 |

**解读**：重心压在驱动轴上，是**牵引力最优**的布局（后驱最怕重心靠前，起步/加速打滑）。
代价是**前支撑几乎不受力 → 只起"防点头"作用，不做承载**，所以：
- ✅ 前支撑**规格要求很低**（承 1kg 足够，随便买个小的都行）
- ✅ 原地转时前轮几乎无摩擦阻力 → **差速原地转更利索**
- ⚠️ 但**前支撑"必须接触地面"**——若高度差 1mm 悬空，车头就会点头/抖动，
  所以 §1.1 的**可调高度机构是必须的**，不是可选项。

### 3.3 ★可调余量（现在不用改，出问题再调）

| 现象 | 调整手段 | 效果 |
|---|---|---|
| 前支撑太轻、过坎抖 | 电池**前移** ≤2cm | 前载 1% → 6%，更贴地 |
| 起步/加速打滑 | 电池**后移** ≤2cm | 驱动轮更压，牵引力更大 |
| 高度差一点 | 加/减垫片 | 直接凑 3.30cm |
| 板面干涉 | 抬 PCB 铜柱 | 每 +1cm 加 1cm 净空 |

> **★ 布局的鲁棒性设计**：电池和 PCB 都用**长条孔/多孔位**固定，
> 允许 ±2cm 纵向滑动调重心——**装好后仍可调**，不用重画底板。
