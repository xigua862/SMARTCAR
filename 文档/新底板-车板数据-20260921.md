# 新底板 · 关键尺寸清单（2026-09-21）

> 用法：画车板时对着抄数。**只列关键尺寸**，不做坐标对照。
> 没有实测的项标"待量"，不硬给。
> 符号：**φ = 直径**（画图时填数字就是直径）；**R = 半径**（圆角填半径）。

## 一、车板本体
| 项 | 数值 |
|---|---|
| 板长（车尾→车头） | **180 mm** |
| 板宽（最宽处，车轮那一段） | **136 mm** |
| 板宽（前段，靠车头那截） | **104 mm** |
| 板宽（车头最前端） | **74 mm** |
| 板厚 | **3 mm**（亚克力） |
| 外角圆角 | **R5** |
| 车头两个角 | **45° 斜切**（别留尖角，减少转弯扫掠） |
| **驱动轴的位置** | **距车尾 30 mm**（靠后，不是正中） |

## 二、PCB（90×70 那块）
| 项 | 数值 |
|---|---|
| 板尺寸 | **90 × 70 mm**（= 9cm × 7cm）✓ 与你说的一致 |
| 孔距 | **83 × 62 mm**（= 8.3 / 6.2）✓ 与你说的一致 |
| 安装方向 | **横放** → **62 那一向沿车长，83 那一向横跨车身** |
| 位置 | 驱动轴**前方**，尽量低（离地 15~25mm）；核心板插拔口朝**车尾** |
| 孔径 | **φ3.2**（配 M3 铜柱） |

## 三、电机
| 项 | 数值 |
|---|---|
| 支架孔距 | **17 mm 正方形四角**（沿用你现在板上那套） |
| 孔位平移 | 轮距 117 → **165**，**每侧 X 向外移 24 mm**；纵向相对驱动轴位置不变（轴后 16.5 / 33.5 mm） |
| 目标轮距 | **165 mm**（打长条孔的话可覆盖 160~175） |
| 孔径 | **φ3.5**（M3 松配，支架孔位精度差一点留余量） |
| 提醒 | 车轮那一段的板宽不能超过 **136**（板半宽 ≤ 轮距/2 − 半轮宽 − 1mm） |

## 四、球脚轮
| 项 | 数值 |
|---|---|
| 触地点位置 | 驱动轴**前方 120 mm** |
| 法兰孔距 | **待量**（你量一下：两个安装孔的中心距）→ 量完我更新 |
| 孔径 | φ3.2 |

## 五、长条板安装区（你自己规划，这里只给可用的位置区间）
| 项 | 数值 |
|---|---|
| 可安装区间 | 驱动轴**前方 85 ~ 145 mm** 这一带 |
| 底板上的固定孔 | 每 **10 mm** 一个孔位（7 个），孔径 φ3.2 |

## 六、其他已知（画板时不用管，但影响布局）
- **电池**：64 × 35 mm，绑在**车尾最后 30 mm** 内
- **降压模块**：叠在 PCB 上方，**不占底板孔**
- **8 路模块**：90 × 30 mm（装在你自己做的前伸长条板上）
