# SolidWorks 学习路线（项目驱动 · 智能车用）

> 2026-09-16 建立。**已安装**：SW 2025，主程序 `D:\SW2025\SOLIDWORKS\SLDWORKS.exe`，桌面有快捷方式；许可服务已注册（SolidWorks Flexnet Server）。
> 目标**不是"学会 SW"**，而是**能做出智能车要用的结构件 + 会导 DXF 给激光切割 + 会装配查干涉**。

---

## 一、第一次打开先改 3 个设置

- [ ] **单位 → MMGS**（毫米-克-秒）：工具 → 选项 → 文档属性 → 单位
- [ ] **备份/临时目录改到 D 盘**：工具 → 选项 → 系统选项 → 文件位置 / 备份，默认写 C 盘（C 盘紧张）
- [ ] **只留 Toolbox 插件**：工具 → 插件，把 CAM / Plastics / Flow Simulation / Visualize 等先取消勾选（启动快）

---

## 二、只学这 4 件事（其余先跳过）

| # | 内容 | 关键点 | 用时 |
|---|---|---|---|
| 1 | **草图 + 尺寸 + 几何关系** | 选基准面 → 画直线/圆/矩形 → **标尺寸** → 几何关系（重合/平行/垂直/对称/相等）| 1 晚 |
| 2 | **特征**：拉伸凸台 / 拉伸切除 / 异型孔向导 / 圆角倒角 | 把草图变实体；孔向导打 M3 安装孔 | 1 晚 |
| 3 | **装配体 + 配合 + 干涉检查** ★ | 插入零件 → 配合（重合/同心/距离/平行）→ **干涉检查** | 1~2 晚 |
| 4 | **导出 DXF/DWG + 工程图** ★ | 零件/装配**导出 DXF** 给亚克力切割；出带尺寸工程图 | 半晚 |

**不用学**：曲面、钣金、Simulation、CAM、Visualize（渲染）。

---

## 三、用智能车当练习（4 个，越做越接近成品）

- [ ] **练习 1（热身）**：90×70×1.6mm 板 + 四角 φ3.2 孔
- [ ] **练习 2（马上能用）**：传感器支架（托板 9×3cm、高 2.3cm、带 M3 孔）→ 导出 DXF
- [ ] **练习 3（★最有价值）**：简化装配 = 底板 + 2 电机 + 2 轮 + PCB + 核心板 + TB6612 + 电池 → **干涉检查**
      要核对的尺寸：PCB 宽 **70mm** 别碰电机/轮子（电机 z=±5.0、本体内缘 ≈±3.75cm）；传感器与 PCB 净空 **0.7cm**；球脚轮转接板位置
- [ ] **练习 4（收尾）**：球脚轮**转接板** 30×30mm（两孔对底板 z=±3.0，中心对球脚轮法兰）→ 导出 DXF

## 四、关键尺寸速查（画图时直接抄）

| 件 | 尺寸 |
|---|---|
| 底板 | 长 **18.5cm**；宽 前 **7.5** / 中 **13.5** / 后 **15.7cm**；厚 3mm |
| 驱动轮 | 直径 **6.6cm**（半径 3.3 → 轴心离地 3.3）|
| 轴距 | **8.5cm**（前支撑 ↔ 驱动轴）；传感中心距驱动轴 **5.0cm** |
| 轮距 | **11.7cm**（后轮中心距）|
| 电机支架孔 | **17mm 正方形四角**，孔径 3.5mm（M3）|
| 8 路模块 | 长 9 × 宽 3cm，离地 1.0cm |
| 电池 | 6.4 × 3.5 × 1.8cm |
| PCB | **90×70mm**，离地 4.0cm，安装孔距 **83×62mm**（±41.5 / ±31）|
| 球脚轮 | 裸高 ≤ 33mm（总高 = 裸高 + 铜柱堆叠 = 3.30cm）|

## 五、怎么学（本项目约定）

1. 卡住 → 截图发我，我针对性讲
2. 看完一节 → **用自己的话讲一遍**，我批改（沿用"自述理解 → 批改"的方式）
3. 练完的模型 → 截图发我，我对着上面的尺寸链核（孔位/净空/干涉）
4. 学的过程中记 CSDN 素材（"用 SW 给智能车建模"这个选题很实用）
