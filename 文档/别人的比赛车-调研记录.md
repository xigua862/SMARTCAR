## 0. 结论速览

| 他的疑问 | 判定 | 依据 |
|---|---|---|
| "多弯道只需要短车" | ✅ **方向对**（短车 + 低重心 + 差速是多弯赛道标准解）；但**不是越短越好** | 龙邱缩微电磁手册原话（见 §2）；厂商同时提醒"短=容错率高、大=性能上限高"要权衡 |
| "短车重心不稳所以要加 IMU" | ❌ **因果关系是错的** | 差速车航向漂移率 = Δv/(B·v)，**只跟左右失配和轮距有关，与轴距无关**（§3 推导） |
| "长车注意速度就不需要 IMU" | ❌ **没有依据**（长车稳态漂移率与短车相同） | 同上 |
| "低趴需要吗" | ✅ **需要，但不是为了防翻**（防翻余量 2.7 倍）；真正理由是**减少左右轮载荷转移、保住内侧驱动轮抓地力** | §2 定量计算 + 龙邱/卓晴多篇 |

## 2. 低趴：需要，但不是为了防翻

**侧翻阈值**：侧向加速度 > (轮距/2)/重心高 · g 才翻车。
以我们的车（轮距 117mm、重心高估 50mm、过 R342 @1.2m/s）：

| 项 | 数值 |
|---|---|
| 过弯侧向加速度 | v²/R = **0.43 g** |
| 侧翻阈值 | (0.117/2)/0.05 = **1.17 g** |
| **安全余量** | **2.73 倍** |
| 先滑还是先翻 | 摩擦极限(μ≈0.8)对应重心高 73mm；我们 50mm < 73mm → **先打滑，永远不翻** |

→ **低趴在这条赛道上完全不是防翻措施。**

**低趴真正的收益 = 减少左右轮载荷转移** ΔN = m·a·h/B（占比与质量无关）：
- 重心 50mm → 转移 **18.3%**；30mm → **11%**；80mm → **29%**
- 差速车靠"左右轮纵向力差"产生横摆力矩。内侧轮卸载 → 它的 μN 下降 → 纵向力不足 → **推头、转弯半径变大、航向抖动**。所以低趴是**给差速车保抓地力**的。

**代价（有据）**：离地间隙、越障、**红外模块的最佳工作高度（1~8mm）**、装配空间。
→ **最优不是"越低越好"，而是"低到不刮底、红外模块仍在最佳高度"。**

## 3. "短车不稳所以要 IMU" → 因果错

差速车运动学：**ω = (v_r − v_l)/B** → 航向漂移率 dθ/ds = ε/B（ε=左右轮速失配率）。

| 失配 ε | 轮距 B | 漂移率 | 跑 5m 后偏航 |
|---|---|---|---|
| 0.5% | 117mm | 2.45°/m | 12.2° |
| 1% | 117mm | 4.90°/m | 24.5° |
| 2% | 117mm | 9.79°/m | 49° |

**轴距 L 根本不出现**。差速车走不直的真因：① 左右不一致（电机/轮径/摩擦）② 轮距 ③ 没有闭环；而且**前轮是自由随动的球脚轮 → 没有自回正力矩 → 航向误差会一直累积** ← 这才是需要 IMU/闭环的真正理由。

**IMU 的合理用途（按对我们的价值排序）**：
1. **丢线/断路时保航向**（配合里程计）← 我们丢线是常态，价值最高
2. **直角弯/环岛的偏航角积分**（龙邱用"积分角 >150 判入环、>735 预出环、>1050 判出环"）
3. **直线段角速度阻尼**（抑制画龙；多支队伍把陀螺仪 Z 轴角速度当 D 项）
→ **但它修不了错误的传感器几何或不合格的控制环**，别指望它当"短车稳定器"。

## 4. 车长：短是对的，但不是越短越好

**龙邱缩微电磁手册原话（最强依据）**：
> "传统车模难以适应的主要原因在于其**车身过长以及较大的转弯半径**。因此…应当着重于**减少车辆长度及减小最小转弯半径**…还需注意将**车体重心集中于转向中心附近，并尽可能降低重心高度**，同时减轻车模重量，减小惯性的影响。"

**厂商同时提醒（光电手册）**：
> "…可以缩小车模尺寸来增加容错率。然而回顾历届大赛，**大车模往往更具优势**。所以需要在**容错率和车模性能上限之间权衡取舍**。"

**为什么短有效（三个机制）**：
1. **转动惯量** I_zz≈mL²/12：车长 0.23→0.30m，转动惯量 **+70%** → 横摆响应更慢
2. **传感器前置量 = 时间滞后**：我们 213mm @1.2m/s ≈ **0.178s ≈ 36 个控制周期**（拓邱控制周期 5ms）→ 直接限制 PD 增益能开多大
3. **车头扫掠/内轮差**：直角弯内侧锥桶距线仅 12cm 的场地上，长车头最容易蹭

**顺带**：差速车在直角弯/Ω 上是**结构性优势**（舵机有死区、阿克曼限制车长、多一个轮分担摩擦），**别改成舵机**。

## 5. 对我们下一版的直接结论

| 项 | 做法 |
|---|---|
| 车长/前瞻 | **缩**（前瞻 213→110、总长 229→~175）✅ 已写入《下一版车型-尺寸建议.md》 |
| 低趴 | **做，但目标是"不刮底 + 红外仍在 5~8mm"**；重点是把**重物压低、靠近驱动轴**：电池贴地压轴（已做 ✓）、**PCB 别架到 4cm 高的叠层**（挪到电机后方低位） |
| IMU | **留着，暂不参与控制**；将来要用就用在：丢线保航向 / 直角与环岛偏航角积分 / 直线角速度阻尼。**不要**为"补短车稳定"而用 |
| 车轮配置 | 保持差速（别改舵机） |
| 装配细节 | IMU 那块 PCB 可考虑加**减震橡胶垫**（高频振动污染陀螺仪）；重物处理方式照头部队伍：**电池贴地/夹在两电机之间** |
