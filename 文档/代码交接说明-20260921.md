# 智能车循迹 · 代码交接说明（2026-09-21）

> 面向：新加入的队友 / 未来的自己。
> 目标：**看完这份能编译、能烧录、能调参、知道哪里不能碰。**

---

## 1. 项目是什么

- **主控**：STM32F103C8T6（核心板插底板），HAL 库 + Keil MDK 工程
- **驱动**：TB6612 双路电机驱动 → 2× JGA25-370 减速电机（差速转向）
- **循迹**：8 路灰度/红外模块（数字量，装在车头前伸的扩展板上，**前瞻可调**）
- **测速**：编码器正交解码（左 TIM3 / 右 TIM4）
- **底盘**：三轮三点（后两轮驱动 + 前球脚轮），3D 打印底板
- **比赛**：5m×5m 场地，**黑底 + 25mm 白线**，含直角弯/十字/Ω 回头弯/相切圆环；到点积分制（到 G 点 100 分），**每队发车 2 次**

## 2. 目录结构

```
代码/
├── Core/
│   ├── Src/  Inc/          ← CubeMX 生成的（main/gpio/tim/usart/it/msp）★ 只改 USER CODE 区
│   └── App/                ← 我们自己写的分层框架
│       ├── app_config.h    ← ★★ 唯一调参入口（参数/开关/引脚表/版本号）
│       ├── app.c/.h        ← 顶层调度（10ms 控制节拍 + 10ms 人机节拍 + 遥测节拍）
│       ├── telemetry.c/.h  ← 串口遥测 + 在线调参（寄存器级中断收命令，防 HAL 卡死）
│       ├── drivers/        ← 硬件抽象层
│       │   ├── motor.c        TB6612 双电机 + 方向映射
│       │   ├── line_sensor.c  8 路加权误差
│       │   ├── speed.c        测速（编码器）
│       │   ├── encoder.c      正交解码
│       │   ├── led.c          三灯（PC13/PB14/PB15，高电平点亮）
│       │   ├── buzzer.c       PA11 PWM 蜂鸣器（非阻塞）
│       │   ├── key.c          启动键（消抖 + 短按/长按）
│       │   └── imu.c          MPU6050（预留，未启用）
│       ├── control/        ← 控制层
│       │   ├── pid.c          通用 PID（抗饱和/微分先行）
│       │   ├── filter.c       一阶低通
│       │   └── line_follow.c  ★核心：PD 差速 + 速度自适应 + 丢线旋转 + 十字强制直行
│       └── fsm/car_fsm.c   ← 状态机：IDLE→按键→COUNTDOWN(3s读秒)→RUN→STOPPED/EMERGENCY
├── Drivers/                ← ST 官方 HAL + CMSIS（别动）
└── MDK-ARM/                ← Keil 工程 test16.uvprojx
```

**分层原则**：`app_config.h` 管参数与开关 → `drivers/` 管硬件 → `control/` 管算法 → `fsm/` 管流程 → `telemetry` 是唯一对外接口。

## 3. 编译与烧录

**Keil**：打开 `MDK-ARM/test16.uvprojx` → `F7` 编译 → `F8` 下载（ST-Link：SWDIO=PA13、SWCLK=PA14、GND；**3.3V 可接但要与车电源共地**）

**命令行编译**（CI/脚本用）：
```
UV4.exe -b "MDK-ARM\test16.uvprojx" -o "MDK-ARM\build.log"
```

**OpenOCD 烧录**（无需开 Keil）：
```
openocd -f interface/stlink.cfg -c "transport select swd" -f target/stm32f1x.cfg ^
        -c "adapter speed 500" -c "program MDK-ARM/test16/test16.hex verify reset exit"
```

**CubeMX 工程**：`test16.ioc`（在根目录），改引脚/外设用它重新生成。

## 5. 串口命令表（115200，**每条命令必须以 `\r\n` 结尾**）

| 命令 | 作用 |
|---|---|
| `P 3.0` | 设 KP（内部放大 10 倍存，范围 0.5~50） |
| `D 0.5` | 设 KD（0~20） |
| `S 60` | 设**直道**速度（弯道自动 = ×0.7） |
| `T 1 40` / `T 2 40` | 单电机测试（**正数 = 前进**）；`T 0 0` 停 |
| `M 40 40` | 直接给左右轮 PWM（进测试模式，`T 0 0` 退出） |
| `L 0~7` | 直接点灯（bit0=LED1、bit1=LED2、bit2=LED3） |
| `B [ms]` | 蜂鸣器响（默认 500ms） |
| `R` | 串口启动（等效按启动键：读秒→跑） |
| `V` | 打印版本横幅 |
| `H` | 诊断：8 路原始位图 + 误差 + 按键 + 编码器计数 |
| `X` | **急停** |

**遥测行**（待机 500ms 一行 / 读秒与运行中 50ms 一行）：
```
FW:0921-2135 IR:10110000 RPM1=210 RPM2=205 KP=3.0 KD=0.0 SP=60 ST=2
```
`ST`：**0=待机 1=读秒 2=运行 3=到站停车 4=急停**

## 7. ⚠️ 必须知道的坑（都是踩过的）

1. **CubeMX 重新生成后必查三处**：
   - `Core/Src/usart.c` 的 `USER CODE BEGIN USART1_Init 1` 里必须有 4 行（WordLength/StopBits/Parity/Mode）——**6.17 版本生成时会吞掉**，导致 `Mode=0` → 串口**收发全废**（现象：TX 能发？不，两边都不通）
   - `Core/Src/main.c` 的 `#include "app.h"` **必须在 `USER CODE BEGIN Includes` 区**里（否则被冲掉 → 编译警告）
   - `.ioc` 里编码器枚举要写 `TIM_ENCODERMODE_TI12`（写成 `EncoderMode_TI12` 编译不过）
2. **`motor.c` 必须 `#include "app_config.h"`**（否则 `#if MOTOR_LEFT_INVERT` 被当成 0 → **方向反转静默失效**；已在文件里加 `#error` 守卫）
3. **接线安全**：8 路模块若供 5V，其 DO 可能是 5V 电平 → **PA0/PA1/PB0/PB1 不耐 5V**，必须先量（本模块实测可直连）
4. **地环路**：烧录和调参别同时插两条 USB（ST-Link + 串口），两个地会打架 → 串口收不到。**一次只插一条**
5. **电池没电 = 电机嗡嗡转不动**（不是代码问题，先量 VM 电压）
6. **`EXTI15_10_IRQHandler` 已删除**（新车不用霍尔）
