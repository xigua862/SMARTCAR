## ② 分层架构与接口头文件清单

```
driver     ← 只碰寄存器/HAL，不懂"车"
  motor.h line_sensor.h encoder.h imu.h odom.h pose.h buzzer.h led.h key.h uart.h
middleware ← 传感融合 + 赛道判据（纯函数：进 pose/读数/里程，出事件；不发指令）
  track.h        （圆环/十字/起终点/失线 判据状态机 + 事件输出）
control    ← 三环（外环转向 / 中环角速度 / 内环速度），只接受"目标+反馈"，不懂赛道
  steering.h angulate.h speeds.h pid.h filter.h
app        ← 状态机 + 调参 + 遥测 + 自检
  car_fsm.h param.h tune.h telemetry.h selftest.h
```

**依赖铁律（违一条即打回）**：
1. 只允许上层依赖下层：`app → control → middleware → driver`；**禁止反向 include、禁止平级互调内部函数**。
2. **判据只读不写**：`track.h` 输出事件/状态枚举，由 `car_fsm` 决定动作；`track.c` 里不允许出现 `motor_*` 调用（旧屎山 1817 行 line_follow.c 就是判据和控制搅在一起的结局）。
3. driver 之间互不认识（imu.c 不许调 odom.c）。
4. 跨层共享的数据结构（`line_reading_t`、`pose_t`、`track_event_t`）**在 middleware 头里定义一次**，driver 只提供原始读数。
5. **新文件先立框架再填肉**：上表 20 个 .h 的函数签名在 M0 任务卡里定死，之后改签名 = 方案级变更 = 回军师。
6. 旧屎山文件（line_follow.c 等）在对应里程碑替换完成后**整文件删除**，不留 `#if 0` 尸体（冗余盘点文档的 A/B/C 档结论）。

## ③ 时间与中断骨架

| 节拍 | 频率 | 跑什么 | 在哪 |
|---|---|---|---|
| 感知+控制 | **1kHz**（TIM1 更新中断；TIM1 让位给蜂鸣器的 CH4 不冲突——只借它的时基，OC 不用） | 读 8 路 GPIO（~0.2µs）→ 融合误差 → 中环+内环 PI → 写 PWM（ARR 预装载，下周期生效）；编码器/陀螺积分读数 | **ISR**，全整数/定点，**无浮点、无 printf、无 I2C 阻塞** |
| SysTick 1ms | HAL 节拍 | 仅 HAL_IncTick + 超时哨兵 | ISR（最低优先级） |
| 判据+决策 | **100Hz** | track.h 全部状态机（里程窗口、角度积分）、圈数、终点动作、速度档切换 | 主循环 |
| 人机/遥测 | 20Hz + 事件驱动 | 行打包 → UART DMA 发送；串口命令解析（RX 中断环形缓冲）；EEPROM(Flash) 落盘只在 IDLE 态 | 主循环 |

**优先级**（NVIC GROUP4）：TIM1-1kHz = 5 > UART = 6 > SysTick = 15。
**栈与临界区**：无 RTOS（沿用 main.c 已停用 FreeRTOS 的决定，删无可删时把 freertos.c 摘出编译列表）；
跨拍共享变量（pose、里程、判据输入）读写用"关中断快照"，临界区 <10µs；ISR 每次执行预算 <150µs（DWT 实测，超 300µs 哨兵置位报警）。
**FreeRTOS 遗留**：`.ioc` 还带着它——框架规定 v2 期间**不重跑 CubeMX 生成**（有破坏工程的事故先例），需要动 .ioc 时走"手改 + 登记"。

## ④ 循迹误差选型：**差比和（除数 = 触发路数 + 1）**

**结论**：采用 `ERR = Σ(w_i·s_i) / (Σ s_i + 1)`，s_i∈{0,1} 为表决后位图，w = -7…+7。
**理由**：
1. 国一源码的差比和之所以抗反射率漂移，关键是**分母带"亮度和+1"**（`adc.c:118-121`）——归一除数跟着亮路数走，换场地/光照不改变量纲。对 8 路**二值**红外，"亮度和"就是触发路数，所以差比和的**精神**落地为"质心 ÷ (路数+1)"。
2. 纯加权质心（旧车做法）在相切点/窄图案下路数在 1↔6 之间跳，ERR 量纲随路数突变 → PD 增益Effective 每帧都在变，这是甩头来源之一。+1 同时兼做除零保护与"少路数时收敛力度"阻尼。
3. ERR 必须由**表决后位图**计算，禁止子样本平均（红外过采样文档 §二的"error 与 raw 同源"约束）。
**不做**的东西：4 电感式的前后对（LY−RY）项——那是给"前瞻在纵向上"的电感阵列用的，8 路单排红外没有纵向分量，抄过来就是伪精度。
**留开关**：`ERR_FORM` 质心/差比和 二选一，默认差比和（+1），供实车 A/B。

## ⑤ 赛道元素判据（每个元素**只留一套**，其余全部编译期默认关闭）

> 总纪律（出口冗余盘点的教训）：**同一件事一个主判据；备选判据必须 `#if` 默认 0 且注释"哪条是主"；未标定的阈值一律不开**。

**公共门**：`pose.h` 提供 (里程 mm, yaw 度[定点])；所有元素判据 = 里程窗口 ∧ 传感形态 ∧ 陀螺角度 三元的组合，缺一个都不许触发。元素互斥：同一时刻只允许一个元素态（入口都带 `其它元素态==0`，学自 19 届元素状态机）。

| 元素 | **唯一判据** | 动作 | 需实测的参数 |
|---|---|---|---|
| **圆环**（E区4环R300 + C区R390） | 五态机 `NONE→ENTER→INSIDE→EXIT→LEAVE`：**ENTER** = 里程落入环窗口 ∧ 连续 N 拍 \|ERR\| 同向饱和；**INSIDE** = **强制 ERR=±r_offset，不再用循迹闭环**（adc.c:133）；**EXIT** = \|∑yaw\|>60°；**LEAVE** = \|∑yaw\|>340°；**超时兜底** = INSIDE 超 T_to 拍强制回 NONE（adc.c:197-205） | 环内走固定偏置，出环交回 PD | 环窗口里程（手推标定 3 次 ±50mm）、r_offset、T_to |
| **十字**（C区 1342×2132） | 里程窗口 ∧ **整排宽图案两端都贴** ∧ 窗口内 \|ERR\| 反复过零 → **该窗口内转向输出=0（直行穿过）** | 只对"直行穿线"是安全的：真十字漏判一帧无害、假十字打废整条弯（复查提醒 §一.1 的风险不对称结论） | 十字窗口里程；旧 CROSS_BUDGET 赛道硬编码层**不开** |
| **起/终点斑马线** | **单一判据四元与**：里程窗口(S、G 各一) ∧ 连续 M 个 1ms 采样 ≥6 路白 ∧ 白-黑周期特征（50mm 间距 → 1.1m/s 时约 45ms 周期，1kHz 可分辨；100Hz 分辨不了，这是判据必须吃 1kHz 流的理由）∧ 圈数达标 → 触发终点动作 | 到 G 急停（不停 -5 分）；**判据不满足就一直跑，绝不在赛道上停车** | S/G 窗口里程、M、≥6 路阈值 |
| **失线** | 连续 K_mm **里程**全灭（按距离不按帧数，提速情报 P2） | **禁止 while(1) 死循环**（pid.c:200-207 是国一车自己的坑）；正确动作 = 减速→按 last_ERR 方向原地转找线→超时且里程不足→判"偏线终止"，进入 FSM 停车流程（可重新发车） | K_mm、找回超时 |

圆环出圈**不再使用任何图案判据**（真相3800 §五：图案 `11000000` 在直角弯/中途拐点双命中，已实测证伪），出环靠 60°/340° 角度积分——与传感器图案无关，物理量免疫直角弯。

## ⑥ 弯道减速（比继续调 PID 值钱）

**物理上限**：全场瓶颈 A 区四连 S 波 R200，μ0.6~0.8 → v_max = √(μgR) = **1.08~1.25 m/s** → 目标车速必须留侧滑余量，取上限的 70~80%。

**公式**（放外环与速度档之间，进弯自动慢出弯自动快，不用状态机）：
```
ratio = min(1, |ERR| / ERR_KNEE)                # ERR_KNEE: 刚够贴住最弯段的误差
v_tgt = v_straight - (v_straight - v_curve) · ratio^1.5      # 幂>1：小误差几乎不减速
每拍斜率限幅: |Δv_tgt| ≤ RAMP (mm/s per 100Hz拍)             # 防 99 瞬跳（旧坑）
内环再叠陀螺阻尼: 目标差速 += GKD · gyro_z                   # 提速情报 P5-1，几乎零成本
转向量限幅 = v_tgt（左右轮目标不为负，防低速抽打/高速打不动，提速情报 P5-2）
```
**两张表（起点值，全部标"待实测"；PWM 档按 RPM≈5.5×PWM 的 12V 实测换算）**：

| 档 | 车速目标 | PWM 档(12V) | RPM 目标 | 依据 |
|---|---|---|---|---|
| 直道 v_straight | 0.80 m/s（一期） | ≈ 46 | ≈ 255 | 现值 34 略提；上限留给出圈验收后再动 |
| 过弯 v_curve | 0.50 m/s | ≈ 29 | ≈ 160 | 现 24×(1.2 提速比)；R200 通过后再探 |
| 二期直道 | 1.0~1.1 m/s | ≈ 60 | ≈ 330 | 触到 R200 物理墙即停 |
| 二期弯道 | 0.55~0.65 m/s | ≈ 35 | ≈ 195 | μ 实测后定 |

ERR_KNEE / GKD / RAMP 均为**必须实车标定**的数——标定前默认保守值并注释"拍的"。

## ⑦ 调参与遥测

- **串口协议**：沿用纯 ASCII 行命令（`P/S/D` 调参、`T/M` 电机、`O/Z` 里程、`R/XX` 发车急停、`V` 版本），新增：`W <addr> <val>` 写判据参数、`E` 全参数读出、`$CSV` 流式遥测（10Hz，行含 FW_TAG 双重确认）。命令表在 `tune.h` 定死，一行命令一条白名单（悬空噪声/二次确认的旧教训保留）。
- **参数持久化**：C8T6 无硬件 EEPROM → **片内 Flash 最后 2 页(0x0800FC00/0x0800F800) 双页轮换伪 EEPROM**，带 magic+版本号+CRC，格式学 `eeprom_data.c`（1KB 参数区思路）。掉电保存"调好的 r_offset/窗口里程/PID"，现场换车不用重调。
- **上电自检**（`selftest.c`，IDLE 态跑，蜂鸣+LED 报结果）：
  1. 红外逐路黑白基准：静置读"白基准"→ 遮光读"黑基准"，任一路异常 → 蜂鸣长鸣 + LED3 闪（每路阈值单独存）；
  2. 陀螺零偏：**放稳静止上电**（记忆教训：上电时移动 → 零偏废掉 → 航位推算闭合差 30%+），零偏超限报警；
  3. 编码器方向：短暂双面点动 → L/R 计数同号校验（里程绝对值法保留兜底）；
  4. 电源/链路：版本行打印 FW_TAG+编译时间；里程流模式做 30 秒串口链路体检。
