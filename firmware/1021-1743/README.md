## 为什么（机制，按代码 + 里程算出来的）

出口右转的判据是两个条件**同时**成立：

```c
OD ≥ GOURD_EXIT_FROM_MM (13194)   &&   某一拍亮 ≥ EXIT_ANOM_LIT_MIN (4 路)
```

- 切点3 真切点（他两次目测：窗口尾 = 车中线与切线平行）≈ **13212**。
- 相切点本身就是"两条线合在一起" ⇒ **宽图案 ⇒ 亮 ≥4 路必然成立**。
- 门槛 **13194 在真切点之前 18mm** 就把闸门打开了 ⇒ 车一到相切点，出口代码立刻硬右转
  （`motor_set_differential` 直接写电机 + 提前 `return`，**优先级最高、谁都抢不走**）。
- ⇒ 表现就是"切点3 猛打右转 / 过不去 / 方向时左时右" —— 很可能一直不是接管在乱，而是**出口代码抢跑**。

历史关系：老文档写"**出口在切点3 之后 82mm**"。真切点 13212 + 82 = **13294**。

## 改动（一个逻辑变量 + 必须成对的那一个）

|---|---|---|---|
| `GOURD_EXIT_FROM_MM` | 13194 | **13294** | = 真切点 13212 + 82；出口代码要等车真的开到 T 型岔口才有资格触发 |
| `GOURD_SPD_TO_MM` | 13194 | **13294** | 速度链必须对齐（1021-1450 的教训：只挪一个就冒出"全速真空"）|
