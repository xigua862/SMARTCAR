## ⚠️ 我预判你会看到的新现象

相切点那种"两条线合成一片白"的图案，去掉接管之后会被 `on_cross` / `wide_long` 判成"**十字/宽图案 ⇒ 强制直行**"
（`WIDE_LONG_GO_STRAIGHT 1`）。所以**切点处最可能变成"直着冲过去"**，而不是"往左拐"。

- 如果直行正好能过 ⇒ 说明以前真正的病就是"接管在选中了一个错误的方向"，那就顺着这条线走；
- 如果直行冲出去/压线 ⇒ 那说明切点处必须有人"推一把"，我们再回到"盲走 e"（或给接管一个确定的方向）。
