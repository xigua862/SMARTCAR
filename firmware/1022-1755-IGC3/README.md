# FW:1022-1755-IGC3（分支 `exp/igc-1023`）= **让 IG 看得见 + 葫芦里再慢一点**

**他的反馈（原话）**：
> "什么鬼东西我看他进去之后这个破 LED 就常亮了那我能看啥，算了你也不用给进圈提醒了，反正进圈会减速，
>  然后就是建议减速再减一点，减到 35%，我怕小车开快了摸不清，然后 3 个 LED IG 涨一下就闪一下，不要亮太久不然我还看啥"

## 改了 5 处（全是"看得见 / 慢下来"，判据逻辑一个字没动）

| # | 项 | 旧 | **新** | 原因 |
|---|---|---|---|---|
| 1 | `GSP_STEADY_MASK`（切点3 窗口三灯常亮）| 0x04 | **0x00（关）** | 就是它把灯"钉"常亮了，看不见 IG |
| 2 | `GSP_BLINK_MASK`（切点1 窗口三灯闪）| 0x01 | **0x00（关）** | 10Hz 连续闪会跟"IG 闪一下"混在一起，先关掉 |
| 3 | 进圈闪灯 | 闪 120ms | **不闪**（只打串口 `IGC enter`）| 他："不用给进圈提醒了，反正进圈会减速" |
| 4 | `IGC_FLASH_MS`（每次 IG+1 的闪灯）| 120 | **50（一下就灭）** | "不要亮太久不然我还看啥" |
| 5 | `GOURD_SPD_STRAIGHT` / `GOURD_SPD_CURVE` | 36 / 24 | **20 / 14** | "减速再减一点，减到 35%"（按 57 的 35% ≈ 20，弯道 = 0.7×20 = 14）|

⚠️ **第 5 条我按"占正常速的 35%"理解**（57 × 0.35 ≈ 20）。
如果你说的是"**档位改成 35**"（36→35），说一句我改成 `35 / 24`，改一个数就行。
