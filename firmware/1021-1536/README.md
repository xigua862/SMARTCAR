**语义（按代码，不按注释）**：`gsp_dir_for()` 返回 **+1 = 选左 / −1 = 选右**，

**为什么这一版值得做（他观察到的"同代码翻面"）**

- ⇒ 接受点前后挪一跳、或前面哪个切点多接一次，切点3 的方向就整个反过来（`line_follow.c:1299` 的注释里写着）。
- 改 `+1` 之后：接管"选左" 与 单向阀"只许左"（`GSP_OW_DIR3 = −1`）**同向** ⇒ 不再互相抵消，切点3 = 确定的往左。
