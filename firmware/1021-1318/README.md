## 还没解决的（别当成已修）

- **右编码器坏的**：手推 3 m `ΔENC2 = -1/0/0`、跑车 `R=0`、架空手转右轮一整圈 `ENC2` 不动。
  里程公式 `(‖d_l|+|d_r|)/2` 会把它的抖动当路程累加（实测手推虚高 11.4%、跑车 16.9%）
  ⇒ **里程随机漂移的头号嫌疑，代码一行没动**。
- **`ENCODER_PPR=422` 是推算值，实测 512**（四次 512/505/509/521）⇒ RPM 读数偏大 21%；
  改它会让同一档位实际车速 +21%，必须连速度档位一起重标 ⇒ 未动。
- 实测左轮 1 计数 = 531 µm ⇒ 配 512 计数/圈 ⇒ 轮径约 86.6mm（设计书写 66mm）⇒ 待卡尺确认。
