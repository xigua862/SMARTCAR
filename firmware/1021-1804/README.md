## 1) 新增：切点3 窗口**末尾** ⇒ 强制左转（`CUT3_KICK_*`）

| 项 | 内容 |
|---|---|
| 触发 | 切点3 **方向窗口的下降沿**（`s_gsp_dir_mask` bit2：上一拍开、这一拍关）= 窗口关掉那一拍 |
| 动作 | `motor_set_differential` 直接写电机 **250ms**，early return（绕过丢线找线 / 十字宽图案 / 接管 / PD）|
| 力度 | `CUT3_KICK_BASE 22` + `CUT3_KICK_PWM 20` ⇒ **左转**时 左 2 / 右 42（右轮快 = 左转）|
| 方向 | `CUT3_KICK_SIDE 0` = **左转**（1 = 右转）|
| 优先级 | **出口右转 > 本功能**（两个都直接写电机，必须定死顺序）|
| 每趟复位 | `line_follow_gourd_rearm()` 里清 `s_c3_prev / s_c3_kick`（R162 那个"一次上电只做一次"的教训）|
| 回退 | `CUT3_KICK_EN` 改 0 |

因为它跟着**窗口掩码**走，所以窗口怎么挪（含串口 `K` 平移）它都自动跟着 —— 现在的窗口尾 = 11376 + 1986 − 150 + 180 = **13392**。

## 2) 出口门槛继续后延：+200

| 宏 | 原 | **新** |
|---|---|---|
| `GOURD_EXIT_FROM_MM` | 13294 | **13494** |
| `GOURD_SPD_TO_MM` | 13294 | **13494**（速度链成对）|

**为什么是 +200 而不是 +100**：强制左转从窗口尾 **13392** 开始、250ms **大约走 90 OD** ⇒ 出口门槛必须排在它之后，
否则出口那记硬右转会在左转中途把它抢走（谁先谁后是硬编码顺序，出口在前）。
13392 + 90 + 余量 ≈ **13494**。若你发现"左转刚完马上就被出口接管"太紧，再 +100（13594）。
