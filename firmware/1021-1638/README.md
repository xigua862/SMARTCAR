## 用法（串口）

| 命令 | 作用 |
|---|---|
| `K` | **只查询**：打印当前平移量 + 11 个生效值（两行长 `W1/W2`）|
| `K <delta>` | **累加**平移：`K 100` = 在现值上再 +100；`K -50` = 往回 50 |
| `K !` | **清零**（回到 `app_config.h` 里的原值）|

- 限幅：**±2000mm**（且保证闸门不会变成负数）。
- ★**建议停车时发**：改的那一拍窗口位置会跳。
- 上电默认 0（= 不改）。
