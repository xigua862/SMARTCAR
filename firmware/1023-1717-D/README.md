## D 与 D2 的唯一差别

| | `GOURD_EXIT_FROM_MM` / `GOURD_SPD_TO_MM` |
|---|---|
| **D** `fw-1023-1717-d` | **13094**（与 1450 完全一致）|
| **D2** `fw-1023-1718-d2` | **13194** = 切点3 窗口尾(13112) + 82 |

**为什么要 D2**：1450 的出口门槛 13094 比切点3 窗口尾 13112 **还早 18**，昨天诊断过"出口代码可能在相切点抢跑"
（1450 那次 11.92V 跑通了，但那是单次）。D2 把它推到窗口尾之后 82 —— 这是老文档"出口在切点3 之后 82mm"的关系。
**如果 D 出现"切点3 处就右转/抢跑"，换 D2。**

## 明天建议顺序

1. **先烧 D**（葫芦完全等价于验收过的 1450）。
2. 只看一件事：**切点3 附近有没有"抢跑右转"**。有 ⇒ 换 **D2**。
3. 葫芦三切点 + 出口 OK 之后，再看槽③/终点（那部分是我们调好的 17200/17655、17775）。
4. 兜底：`firmware/1021-1450/test16.hex`（唯一验收通过的原始二进制，`Oct 21 14:50:33`）。
