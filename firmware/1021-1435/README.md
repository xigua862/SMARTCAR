# FW:1021-1435 = **切点1 打开"只许左"**（单变量；tag `fw-1021-1435`，横幅仍 `1016-R182`）

**他的反馈（原话）**：**"切点很准，但是没有过"** ⇒ 窗口计时已经对了（上一版 `1021-1432` 把后沿当中心 = 正中切点），
所以**剩下的不是里程问题，是方向问题**。按上次说好的下一步，只动一个十六进制数字。

| 项 | 值 |
|---|---|
| 改的宏 | `GSP_ONEWAY_MASK` **0x06 → 0x07**（只多打开 bit0 = 切点1）|
| 方向值 | `GSP_OW_DIR1 = −1` = **只许左**（原有、预置好的，没动）|
| 生效范围 | 切点1 的方向窗口：绝对 OD **11909 ~ 12269**（±`GSP_WIN1_MM` 180）|

**为什么是这一刀**：切点2/3 一直"能用"，靠的是「反向的接管（`GSP_DIR` −1=选右）+ 单向阀（只许右/左）」两股力互相抵消；
切点1 是唯一没开单向阀的切点 ⇒ 反向的接管直接暴露 = 右转回原圈。本版把切点1 的"抵消"补齐。

`GSP_DIR1/2/3`（仍是 −1/+1/−1）、`FW_TAG`。
