# 比赛用稳定版 · 分支 `stable-1023` = **1450 的逻辑（原封不动）+ 12V 分支的里程数**

> 明天比赛。他的要求：**"将这个版本的葫芦弯道逻辑（除了里程数用我们现在 12V 分支下的）替换成那个版本的，要原封不动"**
> ⇒ 做法：**从 `fw-1021-1450`（唯一验收通过的锚点）拉分支**，`Core/` 里的代码**一行没改**，
> 只把 `app_config.h` 里 **12 个里程数字**换成现在 12V 分支（`exp/full-batt-1021`）的值。
> ⇒ 也就是"**机制 = 10-21 15:00 那版验收通过的；刻度 = 现在这套**"。没有任何新功能（没有 `K`、没有三灯常亮、没有强制转、没有 odom 平移）。

## 比赛建议

1. **先烧 B**（出口 13294）：它没有"给强制转让路"这个包袱，出口判据在物理上更对。
2. 如果 B 的**出口右转来得太早**（在切点3 相切点就触发）⇒ 换 A（13494），或用 `git checkout` 到 A 的 hex。
3. **电压**：两版都在 ~12.4V 起步；`11.92V` 那次验收的是 1450 原版（参数不同），别混。
4. 回退到真正的老锚点：`firmware/1021-1450/test16.hex`（`Oct 21 14:50:33`）。
