# G40 葫芦圈修正版 0929-R1

本工程以用户提供的 `SMARTCAR-工程0926-G40` 为基线，与 `SMARTCAR-FW0924-1804` 对比后制作。原工程和工作区 `SMARTCAR` 的未提交改动均保留。本版尚未上车验证，不代表已能稳定通过四个相切圆。

## 使用

- Keil 打开 `MDK-ARM/test16.uvprojx`，目标为 `test16`。
- 固件版本标记应为 `FW:0929-R1`；HEX 为 `MDK-ARM/test16/test16.hex`。
- 仓库附带本次已编译固件 `firmware/0929-R1/test16.hex`，校验值见同目录 `SHA256SUMS`；重新编译的输出仍在上述 Keil 目录。
- 命令行运行 `./build.ps1` 可重新编译，默认使用本机 `C:/keil5/UV4/UV4.exe`。
- 本次仅编译和软件回归，不自动烧录或启动电机。

## 本次修改

1. 修复转向记忆的左右不对称。原程序按差值正负选择“增长/衰减”，又逐拍截断为整数，导致正负方向响应不同。例如恒定 PD 输出为 +23/-23 时，旧算法的长期总修正约为 +23/-39。改用浮点状态，按幅值增减选择速率；方向反转时立即释放旧记忆。新算法两方向镜像对称。这里修复的是软件偏置，电机的物理差异仍由原有左右增益补偿。
2. 一两拍短暂丢线后不再强制把接下来 100ms 的误差压到 ±3。只有真正进入旋转找线后，才启用原有恢复缓冲，并清除旧的误差滤波、转向记忆和速度环历史。
3. 强制直行时同时清除误差滤波和转向记忆，避免“误差设为零但仍沿旧圆转弯”。停车与旋转找线更新真实 PWM 记录，便于区分控制行为。
4. 重新确认在圈内时清零离开计数，确保“连续普通线”确实连续，而不是跨段累加。
5. 测速先处理 16 位计数器双向回绕再取幅值；初始化使用实际计数；同毫秒调用不消耗计数；异常门限随实际时间间隔变化。保留 G40 每拍 ±150RPM 的原响应限制。速度 PID 使用实际测速周期。
6. 默认关闭累计 7600mm 后强制右转。累计轮程在多绕圈后不再对应真实出口，可能在圈中错误起转。本版用于验证自下而上的四圆穿越；末端专用右转需要另行标定。其他出口触发当前同样关闭，不能依赖本版自动完成末端右转。

## 保留的参数与边界

- 直道速度档 30，弯道档 24；KP=2.3、KD=0.92。
- 左轮效率补偿 1.11，右轮 1.00；原有 PWM 下限保留。
- 原 G40 速度 PID 算法和参数保留，没有同时进行速度环大幅重调。
- 不新增定时强制翻向、不提高弯道速度。现有进圈标志可能在普通急弯触发，故未用它新增电机输出限制。

转向记忆修复会改变普通弯道的实际转向响应，即使以上参数未变，也需要复查普通弯。它不能保证选对每个相切点的分支。配置文件保留了历史试验记录，其中“增量式天然不会饱和”等文字不成立，应以实际实现和测试为准。

两包均启用速度闭环，目标换算均为每档 5.5RPM，不能把旧版简单当成开环按 7/11 缩放。当前弯道名义基准目标为 132RPM，差速后两轮分别变化；这不是已经测得的带载速度。没有电池电压采样，本版没有宣称实现自动电压补偿或复现旧版 7V 的真实车速。

已知后续问题：测速接口仍返回转速幅值；原速度 PID 支持负轮速目标，两者在倒转时不一致。为避免本轮同时改变已正常的普通弯道驱动，本次暂未重构该路径。若日志仍显示反复反转、输出大跳变，应下一轮单独验证带方向测速、速度环抗饱和与低速控制。`speed_feedback_valid()` 提供异常反馈状态，本版正常控制尚未用它触发停车；持续零计数也无法仅靠此接口识别为断线。

## 建议的首轮上车对照

1. 使用相同电池电压、轮胎、传感器高度和发车位置，先记录原 G40 的直线与普通弯表现。
2. 烧录 R1，确认版本号；先检查直线、普通左右弯，再从固定入口测试葫芦圈。启动/暂停按键沿用原工程。
3. 连续测试至少 5 次，分别记录三个相切点的成功次数，以及失败是“留在原圆”“摆头丢线”还是“未进入相切点已丢线”。测试四圆后人工停车，避免将未标定的末端出口混入评价。
4. 保存串口 `IR`、`RPM1/2`、`PWM`、`DT` 及回放中的 `e/cor/sp/dcy/flg`。软件测试验证的是控制状态与计算，不是轮胎摩擦、实际车速或赛道通过率。
5. 若普通弯变差，先只把 `Core/App/app_config.h` 的 `USE_SYMMETRIC_CORR_TRIM` 改为 `0`，重新编译对照。此开关仅恢复旧转向记忆算法，其余修复仍保留。完整回退直接使用原 G40 工程。

## 验证

ARMCC 5 完整重编译通过：0 错误、0 警告。构建结果保存在 `MDK-ARM/build-0929-R1.log`。

- `./tests/speed/run.ps1`：9 组测速边界、5 组转向记忆测试通过，其中包括 10,000 拍随机镜像输入。
- `./tests/control/run.ps1`：直接执行实际主控制代码；丢线恢复、旋转恢复、强制直行、进圈计数、停车记录共 5 个场景，默认算法与回退算法各跑一遍，均通过。宿主 GCC 提示原代码双 `if` 同行的格式警告。

测试使用实际 C 实现与模拟输入，不是实车记录。未测试真实硬件运动、11V 满载动态或完整比赛路线。
